# 中间参数文档说明（params.json）

> `clock/params.json` 是本库的**中间参数文档**——所有实验数据元信息、钟比值公式
> 常数、Sr 系统频移分量都以数据形式存在这里，**程序不内置这些参数**。
> `clock/shared.py` 在导入时读取本文件，各分析脚本再从 `shared` 导入。

## 为什么用中间参数文档

后续新增实验数据时，只需：**(1)** 把新拍频文件放进 `clock/data/环外数据（第八列数据）/`；
**(2)** 在 `params.json` 里对应补齐新段的 `groups` 时间窗口、`exclude_ranges`
扣除区间、`shift_a` 五分量；**(3)** 运行分析脚本。**无需改任何代码。**

## 精度约定（重要）

- 所有**高精度小数一律存字符串**（如 `"DELTA_G": "-3.116e-15"`、`"B_YB": "-1.7e-18"`、
  shift_a 分量到 `1e-19`）。
- `shared.py` 用 `Decimal()` 解析字符串，保留 **E-20 精度**（镜像 MATLAB `vpa(...,80)`）。
- **禁止**把这些小数存成 JSON 数字——`json.load` 会转成 float64，丢掉 E-18 级精度
  （这正是本库 `docs/ERROR_CHECKLIST.md` 错误 1 的教训）。
- 整数（N 值、DIV20）也存字符串，统一用 Decimal 解析。

## 字段说明

### `segments.groups`（17 段无跳点窗口）

每个元素是 `["开始时间", "结束时间"]`，**北京时间（UTC+8）**。共 17 段。
时间格式 `YYYY-MM-DD HH:MM:SS`。

### `segments.exclude_ranges`（手动扣除区间）

每个元素是 `["开始", "结束"]`，北京时间。来自 MATLAB `exclude_ranges`，共 12 个区间。

### `ratio_constants`（钟比值公式常数）

| 字段 | 含义 | 值 |
|---|---|---|
| `N1156` | Yb 1156 nm 光梳计数 | 1295739 |
| `N1397` | Sr 1397 nm 光梳计数 | 858456 |
| `N1550` | 1550 nm 传递链路计数（上海端） | 773598 |
| `N1550_WH` | 1550 nm 传递链路计数（武汉端） | 966996 |
| `FREF` | 梳齿重复频率基准（Hz） | 1e7 |
| `DIV20` | 分频 | 20 |
| `b_yb_raw_530` | Yb 频移原始项 5.3e-18 | 5.3e-18 |
| `b_yb_raw_700` | Yb 频移原始项 7e-18 | 7e-18 |
| `DELTA_G` | 静态引力红移修正 | -3.116e-15 |

> `B_YB = b_yb_raw_530 − b_yb_raw_700 = -1.7e-18`（由 `shared.py` 计算，不直接存）。

### `shift_a`（Sr 系统频移五分量）

| 字段 | 含义 | 量级 |
|---|---|---|
| `a_rou` | 光晶格 AC-Stark 频移 | ~-3.5~-1.5×10⁻¹⁹ |
| `a_AC` | 交流斯塔克频移 | +7.44×10⁻¹⁸ / +8.93×10⁻¹⁸ |
| `a_SM` | 二阶塞曼频移 | ~-1.78×10⁻¹⁶（7月）/ -8.925×10⁻¹⁷（段9）/ 0（段10-14） |
| `a_air` | 空气折射率修正 | -6.7×10⁻¹⁹ |
| `a_BBR` | 黑体辐射频移 | 0 |

每个字段是长度为 14 的数组（对应段 1-14）。第 15/16/17 段由 `shared.py` 自动沿用
段 12-14 的常数 shift_a（`SHIFT_A_14[11]`），无需在 params.json 里重复。

> **遗留疑点**：段 9 的 `a_SM = -8.925e-17` 与段 10-14 的 `a_SM = 0` 差 8.925e-17，
> MATLAB 源码自注「8 月 a_SM=0 请确认是实际修正值还是占位符」。本库按「尊重原始
> 数据」原则原样保留。
