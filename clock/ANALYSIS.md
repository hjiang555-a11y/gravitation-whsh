## 1. 物理链路

潮汐引力势差 ΔW 通过广义相对论引力红移改变两地钟的频率差：

```text
Δf/f = ΔW / c²        ΔW = W(WUHN) − W(SHAO)   [m²/s²]
```

拍频（beat）与钟频分差的关系由处理程序 `Dr` 公式给出：

```text
Δf/f = COEF × beat[Hz]
COEF = coef1156/N1156 / (fref × div20) / den = 4.282082163269648e-15
```

其中 `coef1156 = (1 + b_Yb)/2`、`N1156 = 1295739`、`fref = 1e7`、`div20 = 20`、
`den = coef1397/N1397 × (N1550 + 7/25 + 1/25)`。因此潮汐预测在拍频单位下为：

```text
beat_tide[Hz] = (ΔW / c²) / COEF
```

## 2. 已修正的错误

### 2.1 时间戳时区（北京 → UTC）

原始拍频文件头标注 `PC time, time zone local`，采集机在中国（UTC+8），实验拍频
与 PDF 的 17 段窗口时间均为**北京时间（UTC+8，已确认）**；而潮汐 CSV 为 UTC。
早期脚本把两者直接比对，错位 8 小时（≈ 半日潮 M2 的半周期）。修正：所有会话
窗口与拍频时间戳 `− 8 h` 后再与潮汐数据对齐。结论时间轴统一按北京时间（UTC+8）
呈现。

### 2.2 换算系数（÷COEF 而非 ×F_BEAT）

旧脚本用 `×F_BEAT`（F_BEAT ≈ 33.6 MHz）换算，错误 7 个数量级。正确是
`beat = (Δf/f) / COEF`。

### 2.3 时间戳 ±1 s 抖动

每个数据文件的时间戳带 ±1 s 标签抖动（`dt=0` 与 `dt=2` 成对出现，首尾漂移=0），
数据本质是均匀 1 s 采样。MATLAB 处理程序**忽略文件时间戳**，按「首点 + 均匀 1 s」
重建时间轴。早期用严格 `dt==1` 判连续会把数据切碎（组 13 被误判成 13.4 h 而非
42.5 h）。修正：按 MATLAB 约定重建均匀时间轴。

### 2.4 幅度拟合去均值

潮汐模板在单个会话窗口内有非零的会话平均（DC 分量），而拍频已去均值。若直接
`A = dot(tide, beat)/dot(tide, tide)` 会用未去均值的 tide 混入虚假 DC 贡献，导致
`A` 与相关系数 `r` 符号矛盾（如组 14 曾出现 A=+1.32 但 r=−0.38）。修正：两者都
去均值（等价于带截距拟合），`A = r·σ_beat/σ_tide`，符号与 r 一致，物理上只衡量
潮汐**变化**幅度是否以预期比例出现。

## 3. 17 段无跳点批量分析

统一方法（[segment_analysis/batch_analysis.py](segment_analysis/batch_analysis.py)）：

1. 按 MATLAB 约定重建均匀 1-s 时间轴（忽略时间戳抖动）；
2. 套用 MATLAB 的 `exclude_ranges` 手动扣除时段；
3. 剔除偏离中位数 >10 Hz 的跳点（中位数取物理合理范围 3e7–4e7 内，排除计数器
   饱和值 131072000 等）；
4. 取剩余有效、1-s 连续数据中的**最长连续段**（即 MATLAB 的「无跳点」trace）；
5. 1200 s 三角（Bartlett）窗口、600 s 步长（50% 重叠）积分——**拍频与潮汐数据
   用同一窗口投影**（潮汐先建 1-s 序列再同窗积分，非窗口中心点采样）以保证相关
   系数评估公平；
6. 去均值后幅度拟合 `beat = A·tide + noise`，A=+1 表示潮汐以理论幅度完整正向出现。

### 3.4 关键发现：跨段一致的相关性

**17 段中有 14 段相关系数同号，合并后极显著（符号无关 Stouffer |z| = 5.87，
p≈4.3e-9）。**单独看多数段不显著（噪声淹没的必然结果），但**符号高度一致**
（14/17 同负）在合并后远超随机预期（二项 p = 0.0127）。

这一致的相关性说明实测拍频与潮汐数据之间存在**真实的、弱的统计关联**（加权
|r| ≈ 0.13，新增的第 15–17 段相关系数绝对值较小，稀释了合并 r，但符号一致性
与合并显著性仍稳健）。注意：相关系数的**正负号标签取决于数据的方向约定**（见
§5），但**相关性的存在性、强度与显著性都与符号无关**——把数据整体取反，r 翻号、
|r|、p 值、符号一致性、合并显著性全部不变。因此「存在统计关联」这一结论独立
于符号方向。

## 4. 会话均值相关性（y_i，暂 14 段）

用 `clock_tidal_shift.py` 计算各会话窗口内的平均潮汐频差 Δf/f，与会话比值
偏差 y_i（`y_i = R_i/R_ref − 1`，由 MATLAB 处理程序精确计算）做相关：

| 统计量 | 数值 |
|---|---|
| Pearson r | +0.544，p = 0.044 |
| Spearman ρ | +0.587，p = 0.027 |
| n | 14 |

**结论**：方向为正、相关性较旧模板（+0.355）提升，已**达 0.05 显著**（p=0.044；
段 4/11/14 会话窗口修正后 r 由 +0.458 升至 +0.544）。此处
`correlation_analysis.py` 里存放的是低精度（两位小数）读数，仅作快速定性检查；
y_i 本身由 MATLAB 以 80 位精度定义。注意：此处 y_i 的方向约定可能与拍频
段的符号方向相反（会话比值是 Yb/Sr 频率比，拍频是传递链路量），故本节的 +r 与
§3 的 −r 不矛盾。

## 5. 待定问题：符号方向（已收敛为单一因子）

幅度拟合 A 的**正负号标签**取决于实验布局，但**不影响相关性结论**：

1. **Yb 钟、Sr 钟分别部署在哪一站**（已推导：Yb 武汉、Sr 上海，见
   [SIGN_COEFFICIENT_ANALYSIS.md](SIGN_COEFFICIENT_ANALYSIS.md)）；
2. **拍频的物理方向**（已确认：来自远端）；
3. **梳尺（光频梳）频率高还是本振频率高**（`s_beat = ±1`，唯一未定项）。

**符号只决定 r 的标签正负号**，不改变检出结论：

> 17 段拍频数据与潮汐数据存在**显著的、弱的相关性**（符号无关 Stouffer
> |z|=5.87，p≈4.3e-9，加权 |r|≈0.13）。单段不显著但符号高度一致（14/17 同负）。
> 这一结论**不依赖符号约定**。

符号方向的物理解读（潮汐效应是正方向还是反方向）需待 `s_beat` 确认后补充，
但它只回答「效应朝哪边」，不影响「效应是否存在」。

## 6. 根本原因：信号被噪声本底淹没

潮汐引力红移信号（Δf/f ~1e-18 量级）被 1550 nm 环外链路拍频噪声淹没：

| 量 | Δf/f |
|---|---|
| 潮汐信号 rms（段 13） | 4.76e-18 |
| 1-s 拍频噪声 | 1.92e-15（比信号大 ~400 倍） |
| 1200-s 积分后噪声 | 1.73e-17（仍比信号大 ~3.6 倍） |

噪声模型（经确认）：光纤链路为**白相位噪声**（Allan σ ∝ 1/τ，频率 PSD ∝ f²，
在潮汐超低频段几乎为零），钟为**白频率噪声**（σ ∝ 1/√τ，频率 PSD 平坦）。真正
的潮汐检测本底是钟的白频率噪声；段 13 的 Allan 方差在 τ ≳ 8000 s 后趋平，是
潮汐信号（12.4 h / 24 h 周期，M2 等）与缓慢温漂顶住方差所致，非链路本征闪烁。
**单段幅度拟合必然不显著**；只有跨段合并才能把一致的符号趋势累加出来（§3.3）。
要精确定量潮汐幅度，需更低的白频率噪声本底（两钟直接比对）或更多独立段。
