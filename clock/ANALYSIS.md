# 光钟比对潮汐引力红移相关性分析报告

> 本报告总结 `clock/` 目录下对「武汉—上海光钟（Yb/Sr）比对」中潮汐引力红移效应
> 是否可检出的完整分析。理论量来自 `results/wuhan_shanghai_20260620_20260826.csv`
> （本项目固体潮 + 海潮负荷总势差 ΔW），实测量来自 1550 nm 环外链路拍频
> （FXE_B8，~33.6 MHz）与 `atomic-clock-comp.pdf` 的 14 组实验记录。

---

## 1. 物理链路

潮汐引力势差 ΔW 通过广义相对论引力红移改变两地钟的频率差：

```text
Δf/f = ΔW / c²        ΔW = W(SHAO) − W(WUHN)   [m²/s²]
```

拍频（beat）与钟频分差的关系由处理程序 `Dr` 公式给出：

```text
Δf/f = COEF × beat[Hz]
COEF = coef1156/N1156 / (fref × div20) / den = 4.282082163269648e-15
```

其中 `coef1156 = (1 + b_Yb)/2`、`N1156 = 1295739`、`fref = 1e7`、`div20 = 20`、
`den = coef1397/N1397 × (N1550 + 7/25 + 1/25)`。因此潮汐预测在拍频单位下为：

```text
beat_tide[Hz] = (ΔW / c²) / COEF
```

## 2. 已修正的两处关键错误

### 2.1 时间戳时区（北京 → UTC）

原始拍频文件头标注 `PC time, time zone local`，采集机在中国（UTC+8）；而潮汐
CSV 由主程序以 UTC 生成。早期脚本把两者直接比对，错位 8 小时（≈ 半日潮 M2 的
半周期）。

证据链：
1. 数据文件头 `PC time, time zone local`；
2. 地震分析一致性：宫古岛地震 `7.3 04:04 UTC` 落在「组 4 结束 7.3 07:51 之后、
   组 5 开始 7.3 17:34 之前」，只有在组时间为**北京时间**时才成立；
3. 潮汐 CSV 由 `datetime(..., tzinfo=utc)` 明确生成。

修正：所有会话窗口与拍频时间戳 `− 8 h` 后再与潮汐模板对齐。

### 2.2 换算系数（÷COEF 而非 ×F_BEAT）

旧脚本 `segment13_analysis.py` 用 `×F_BEAT`（F_BEAT ≈ 33.6 MHz）把潮汐频差换算成
拍频，错误 7 个数量级（潮汐拍频被算成 1e-10 Hz，实际 ~1e-3 Hz）。正确换算是
`beat = (Δf/f) / COEF`，系数 `COEF` 从 MATLAB `Dr` 公式精确推导。

> 注：Pearson 相关系数对线性缩放不敏感，故旧脚本的 r 值方向正确，但**幅度/斜率
> 的解释全部错误**。

## 3. 无跳点段逐段分析

采用统一方法：1200 s 三角（Bartlett）窗口、600 s 步长（50% 重叠），幅度拟合

```text
beat_i = A × tide_i + noise_i
```

`A = +1` 表示潮汐引力红移以理论幅度**完整、正向**出现；`A = 0` 表示无潮汐信号。

### 3.1 第 13 组（跳点自由，42.5 h）

- 窗口（北京）：2026-08-11 05:30 ~ 2026-08-13 00:00，153,000 点，**0 跳点**
- 1-s 拍频噪声：0.449 Hz → Δf/f ≈ **1.92e-15**
- 潮汐模板：rms 1.111e-3 Hz → Δf/f rms ≈ **4.76e-18**
- 1200-s 积分后噪声：0.00403 Hz → Δf/f ≈ **1.73e-17**

| 窗口 | 积分噪声 | 幅度拟合 A | u_A | A 离 +1 |
|---|---|---|---|---|
| 600 s | 0.00555 Hz | −0.30 | 0.31 | 4.2σ |
| 1200 s | 0.00403 Hz | **−0.39** | **0.23** | **6.1σ** |

**结论**：A = −0.39 ± 0.23，与 0 相容，离理论值 +1 约 6.1σ——潮汐引力红移在
第 13 组拍频数据中**不可检出**。信号（rms 4.8e-18）比积分后噪声（1.7e-17）
小约 3.6 倍（信噪比 ~0.28），被 1550 nm 链路噪声淹没。

### 3.2 第 6 组（跳点自由，10 h 可用）

- 官方窗口（北京）：7.4 19:30:46 ~ 7.5 10:00，14.49 h；但仓库缺 `Freq_B_2_260704`
  文件，实际仅有后半段 **10 h**（7.4 23:59:55 ~ 7.5 10:00），0 跳点、1-s 连续
- 1-s 拍频噪声：0.699 Hz → Δf/f ≈ **2.99e-15**
- 潮汐模板：rms 5.10e-4 Hz → Δf/f rms ≈ **2.19e-18**
- 1200-s 积分后噪声：0.00196 Hz → Δf/f ≈ **8.39e-18**
- **幅度拟合 A = −0.26 ± 0.50**（离 +1 约 2.5σ）

**结论**：同样未检出，且方向与第 13 组一致为负。两组各自不显著，但负号方向
一致（见 §5）。

## 4. 14 组会话均值相关性

用 `clock_tidal_shift.py` 计算 14 组会话窗口内的平均潮汐频差 Δf/f，与 PDF 散点图
数字化得到的会话比值偏差 y_i 做相关：

| 统计量 | 数值 |
|---|---|
| Pearson r | +0.355，p = 0.213 |
| Spearman ρ | +0.442，p = 0.114 |
| OLS 斜率 | +1.03（仅量级参考） |
| n | 14 |

**结论**：方向为正，但**不显著**（p > 0.1），14 个点不足以拒绝零假设。

**重要限制**：y_i 是从 PDF 散点图（"Yb/Sr: 14 longest continuous runs"）**数字化
（像素坐标）**的近似值。Pearson r 对仿射缩放不变故 r 值可靠，但 OLS 斜率/截距的
绝对值不可信。精确结论需精确的 14 组比值数据。

## 5. 待定问题：符号方向

幅度拟合 A 的**正负号**取决于实验布局，而当前代码与 PDF 均未明确两条信息：

1. **Yb 钟、Sr 钟分别部署在哪一站**（武汉 WUHN / 上海 SHAO）：
   - 若 Yb 在 SHAO、Sr 在 WUHN → 潮汐模板 = `+ΔW/c²`，A 应趋 +1；
   - 若 Yb 在 WUHN、Sr 在 SHAO → 潮汐模板 = `−ΔW/c²`，A 应趋 −1。
2. **拍频 `dm` 的符号约定**：`dm > 0` 对应哪端钟频率偏高。

当前分析默认第一种（A 应趋 +1），得到 A = −0.39 / −0.26。若实际布局相反，A 翻号
为 **+0.39 / +0.26**，恰落在「潮汐正向部分体现」方向。

在符号方向确认前，最终判定为：

> **在当前符号假设下，两组无跳点段的潮汐引力红移均不可检出**（A 与 0 相容，且
> 离 +1 约 2.5–6.1σ）；两组 A 方向一致为负这一现象，尚无法排除「符号方向搞反」
> 或「纯噪声偶然」两种解释。

## 6. 根本原因

潮汐引力红移信号（Δf/f ~1e-18 量级）被 1550 nm 环外链路拍频噪声淹没：

| 量 | Δf/f |
|---|---|
| 潮汐信号 rms（段 13） | 4.76e-18 |
| 1-s 拍频噪声 | 1.92e-15（比信号大 ~400 倍） |
| 1200-s 积分后噪声 | 1.73e-17（仍比信号大 ~3.6 倍） |

链路噪声非白频（积分 42.5 h 后仍 ~1.7e-17），而潮汐信号主要在 12.4 h 周期
（M2）附近，更长积分窗无法进一步压噪。要检出潮汐红移，需要：更低的链路噪声本底，
或直接使用两钟的频率比对数据（而非 1550 nm 传递链路拍频）。
