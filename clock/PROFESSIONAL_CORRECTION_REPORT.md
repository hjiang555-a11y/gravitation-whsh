# 专业潮汐数据修正与固化报告

将专业人士提供的 30 秒间隔潮汐结果 `武汉-上海潮汐结果（0620-0910）-30秒间隔数据.xlsx`
作为权威海潮负荷来源，**修正并固化**本项目的引力潮汐计算方法，并重跑全部下游分析。

## 1. 单位与方向（已厘清并固化）

xlsx 列结构与公式：

| 列 | 含义 | 公式 |
|---|---|---|
| B/C | 固体潮（mm）：CAS / SHA | — |
| E/F | 海潮（mm）：CAS / SHA | — |
| `固体潮之差` | = CAS − SHA | `=B−C` |
| `海潮之差` | = CAS − SHA | `=E−F` |
| `综合差` | = 固体潮之差 + 海潮之差 | `=H+I` |

- 专业数据时间戳为 **UTC**（交叉验证：与 DE440 星历固体潮在同刻对齐 corr=+0.99996，
  无 8 h 偏移），换算序列已在 `data/professional_ocean_loading_30s.csv` 与
  `results/professional_tidal_delta_30s.csv` 中以 UTC 标注 `Z` 固化。
- 专业「之差」列的**数值方向**经验证为 **上海−武汉**（与项目 `SHAO − WUHN` 约定
  一致），尽管 xlsx 表头文字标注为「CAS−SHA」。判据：海潮 SHA（上海，沿海）幅度
  ~26.6 mm std 远大于 CAS（武汉，内陆）~6.7 mm std，物理上上海海潮负荷必然远大于
  武汉；「海潮之差」数值 = SHA − CAS。因此**符号无需翻转**，直接同号代入。
- 引力势差换算：`ΔW = g·(mm)/1000`，g ≈ 9.794 m/s²（与固化的 CSV 字节一致）。
- 潮汐引力红移：`Δf/f = ΔW/c²`；拍频模板：`beat = Δf/f / COEF`（COEF=4.282e-15）。

## 2. 计算方法修正（已固化到代码）

原实现的海潮负荷来自 HARPOS FES2014b 44 分潮，其幅度相对专业数据**偏低约 3.9 倍**
（std 比 0.0605 vs 0.2358 m²/s²），是「综合差」幅度偏差的主因。修正方案：

- [calculator.py](../../src/gravitation_whsh/calculator.py) 新增
  `--professional-ocean` 可选参数与 `load_professional_ocean()`；当提供该权威序列时，
  以 `np.interp` 插值到分钟网格**覆盖** HARPOS/BLQ 海潮负荷。
- 优先级：`professional_ocean_csv` > `_harpos` > `_blq`。
- 符号约定：专业序列已按上海−武汉方向固化，直接同号代入（`tests/test_calculator.py`
  新增 `test_load_professional_ocean_preserves_sign_and_epochs` 锁定符号不翻转）。
- 主结果 `results/wuhan_shanghai_20260620_20260826.csv` 已用
  `--professional-ocean` 重新生成，海潮列现与专业数据一致（corr=+1.0000）。

## 6. 结论

1. **方向一致**：专业数据与本项目数值方向一致（综合差 corr=+0.9997），无系统性
   符号错误；xlsx 的「CAS−SHA」表头是按列公式的标签，数值方向实为上海−武汉。
2. **唯一需要修正的是海潮负荷**：HARPOS FES2014b 幅度偏低 ~3.9×，已用专业权威
   序列替换并固化（`--professional-ocean`）；固体潮仅 −5.2% 幅度差、波形一致，属
   Love 数完整性差异，非错误。
3. **14 组数据已补全**：组 1–5 因 `batch_analysis.py` 漏加载 `2606*.txt`（6 月）文件
   而此前显示「无数据」，现已修复并跑通全部 14 段。
4. **跨段合并结论增强**：负相关段 12/14（原 8/9 段中 8 段为负），Stouffer |z| = 6.33
   （p=2.5e-10），加权 r = −0.173，A = −0.52±0.08（6.8σ）——潮汐引力红移以负方向、
   约一半幅度被一致检出，结论比旧模板更强。
5. **会话层 y_i 相关性提升**：Pearson r 0.355→0.472（p 0.213→0.088），专业模板对齐
   更好（样本仍偏小、未达 0.05 显著）。
