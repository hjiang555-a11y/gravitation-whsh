### 1.1 拍频 → 比值偏移系数 COEF

由第 917–918 行的 `Dr` 公式：

```text
Dr = coef1156/N1156 × (mean_dm / fref / div20) / den
den = coef1397/N1397 × (N1550 + 7/25 + 1/25)
```

代入精确值：

```text
COEF = 4.2820821632696486e-15     （beat[Hz] → 比值偏移，无量纲）
```

即 **Δ(比值) = COEF × 拍频偏差[Hz]**，等价于 `beat = (Δf/f) / COEF`（批处理
脚本所用系数，方向已对齐）。

### 1.2 静态引力红移 delta_g

```text
delta_g = −3.116e-15
ΔW_static = delta_g × c² = −280.05 m²/s²
Δh = ΔW_static / g ≈ −28.6 m（正高差）
```

## 2. 符号链（从代码逐行）

```text
dm         = beat − median(beat)        第 898–899 行，拍频偏差（>0 = 拍频高于中位）
Dr         = +COEF × mean_dm            第 917–918 行，正系数
ratio_group(Sr/Yb) = ratio_base + Dr   第 1038 行，Dr 加在 Sr/Yb 比值上
```

**结论**：拍频↑ → Dr↑ → Sr/Yb 比值↑。整条链无负号，`COEF > 0`。

---

## 3. 站点布局推导（从 delta_g 符号）

代码第 139–140 行：

```text
YbSr_corr = YbSr_raw × (1 + delta_g)       YbSr = f_Yb/f_Sr
```

引力红移物理：`f_Yb/f_Sr = (f_Yb⁰/f_Sr⁰) × (1 + (W_Yb − W_Sr)/c²)`。修正要抵消
此效应，故 `delta_g = (W_Sr − W_Yb)/c²`。

```text
delta_g = −3.116e-15 < 0  →  W_Sr < W_Yb  →  Sr 在低势处，Yb 在高势处
```

结合地理（上海沿海正高 ~20 m、武汉内陆正高 ~50 m）与第 467 行注释
「实测**武汉端** beat」：

> **Yb 钟在武汉（WUHN），Sr 钟在上海（SHAO）。**

---

## 4. 潮汐模板符号（最终判定）

潮汐时变下，Sr/Yb 比值的偏移为：

```text
δ(Sr/Yb) = δf_Sr/f_Sr − δf_Yb/f_Yb = (δW_Sr − δW_Yb)/c²
         = (W_SHAO − W_WUHN)/c² = ΔW/c²
```

其中 ΔW = `total_tidal_delta_m2_s2`（本项目 CSV）。由 §2 的 `Dr = COEF × dm`：

```text
拍频潮汐模板 = +ΔW/c² / COEF      （正号）
```

**这与批处理脚本 `batch_analysis.py` 使用的符号一致**（`tidal_beat` 返回
`+ΔW/c²/COEF`）。

---

## 5. 关键发现：代码正号 vs 实测负相关

按 §4 的符号约定，若潮汐引力红移以理论方向完整存在，实测拍频应与模板
**正相关**（A 趋 +1）。但批处理实测结果为 **8/9 段负相关**（Stouffer z = −4.2，
p<0.001）。

符号链本身（§2）无歧义、系数为正，故矛盾的可能来源是：

1. **FXE_B8 拍频的物理方向**（最可能）：第 8 列拍频是有符号差频 `f_远端 − f_本地`
   还是 `f_本地 − f_远端`，代码未明说。若实际方向与代码 `Dr = +COEF·dm` 的假设
   相反，则潮汐模板整体取反号，实测负相关即变为**正确方向的正相关**。
2. **潮汐被噪声淹没**：单段 r 均弱（|r|≤0.38），8/9 同号在二项检验下 p=0.02，
   尚不能完全排除偶然（但概率低）。

## 6. 结论

| 项 | 结果 |
|---|---|
| 拍频→比值系数 | `COEF = 4.2820821632696486e-15`（正） |
| 静态引力红移 | `delta_g = −3.116e-15`（对应 −28.6 m 正高差） |
| 布局 | **Yb 在武汉（WUHN），Sr 在上海（SHAO）** |
| 潮汐模板符号（代码约定） | **+ΔW/c² / COEF**（与批处理一致） |
| 实测 | 8/9 段负相关，与代码正号矛盾 |

**下一步**：确认 FXE_B8（第 8 列）拍频的物理方向定义（`f_远端 − f_本地` 还是
反之），即可定死潮汐模板最终符号。若方向相反，则潮汐引力红移以**正确方向、
部分幅度**（|r|≈0.17）被检出。
