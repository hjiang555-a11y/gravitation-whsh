### 1.1 拍频 → 比值偏移系数 COEF

由第 917–918 行的 `Dr` 公式：

```text
Dr = coef1156/N1156 × (mean_dm / fref / div20) / den
den = coef1397/N1397 × (N1550 + 7/25 + 1/25)
```

代入精确值：

```text
COEF = 4.2820821632696486e-15     （beat[Hz] → 比值偏移，无量纲）
```

即 **Δ(比值) = COEF × 拍频偏差[Hz]**，等价于 `beat = (Δf/f) / COEF`（批处理
脚本所用系数，方向已对齐）。

### 1.2 静态引力红移 delta_g

```text
delta_g = −3.116e-15
ΔW_static = delta_g × c² = −280.05 m²/s²
Δh = ΔW_static / g ≈ −28.6 m（正高差）
```

## 3. 站点布局推导（从 delta_g 符号）

代码第 139–140 行：

```text
YbSr_corr = YbSr_raw × (1 + delta_g)       YbSr = f_Yb/f_Sr
```

引力红移物理：`f_Yb/f_Sr = (f_Yb⁰/f_Sr⁰) × (1 + (W_Yb − W_Sr)/c²)`。修正要抵消
此效应，故 `delta_g = (W_Sr − W_Yb)/c²`。

```text
delta_g = −3.116e-15 < 0  →  W_Sr < W_Yb  →  Sr 在低势处，Yb 在高势处
```

结合地理（上海沿海正高 ~20 m、武汉内陆正高 ~50 m）与第 467 行注释
「实测**武汉端** beat」：

> **Yb 钟在武汉（WUHN），Sr 钟在上海（SHAO）。**

## 4. 潮汐模板符号（最终判定）

潮汐时变下，Sr/Yb 比值的偏移为：

```text
δ(Sr/Yb) = δf_Sr/f_Sr − δf_Yb/f_Yb = (δW_Sr − δW_Yb)/c²
         = (W_SHAO − W_WUHN)/c² = ΔW/c²
```

其中 ΔW = `total_tidal_delta_m2_s2`（本项目 CSV）。由 §2 的 `Dr = COEF × dm`：

```text
拍频潮汐模板 = +ΔW/c² / COEF      （正号）
```

**这与批处理脚本 `batch_analysis.py` 使用的符号一致**（`tidal_beat` 返回
`+ΔW/c²/COEF`）。

## 5. 拍频物理方向与 s_beat 因子（新进展）

用户已确认拍频来自**远端**，但还有一个符号因子未定：**梳尺（光频梳）频率 vs
本振频率谁高**。记 `s_beat = ±1`，这是潮汐模板符号的最后一块拼图。

### 5.1 拍频的物理构成

```text
beat = s_beat × (f_comb − f_remote)

  comb   = 光频梳（本地振荡器），锁定 Yb 钟（武汉 WUHN）
  remote = 远端光，即上海 Sr 光（SHAO），经 1550 nm 链路传回

  s_beat = +1  →  梳尺频率 > 本振频率  →  beat = f_comb − f_remote
  s_beat = −1  →  本振频率 > 梳尺频率  →  beat = f_remote − f_comb
```

### 5.2 潮汐对拍频的影响

潮汐引力红移改变光学载波频率（f_opt ≈ 193.4 THz，1550 nm）：

```text
δf_comb   = f_opt × δW_Yb / c²        （comb 锁 Yb，武汉）
δf_remote = f_opt × δW_Sr / c²        （remote = Sr，上海）

δbeat = s_beat × (δf_comb − δf_remote)
      = s_beat × f_opt × (δW_Yb − δW_Sr) / c²
      = −s_beat × f_opt × ΔW / c²         ΔW = W_SHAO − W_WUHN
```

数值核对：f_opt × ΔW/c² ≈ 1.934e14 × 5e-18 ≈ **9.7e-4 Hz**，与批处理脚本的
潮汐拍频 rms（1.1e-3 Hz）量级一致。

### 5.3 代码 COEF 隐含的 s_beat

代码 `Dr = +COEF × δbeat`（COEF > 0），而物理上 δ(Sr/Yb) = ΔW/c²：

```text
ΔW/c² = COEF × δbeat = COEF × (−s_beat × f_opt × ΔW/c²)
⇒  代码 COEF 的正号隐含 s_beat = −1（本振频率 > 梳尺频率）
```

即：**当前 `batch_analysis.py` 的模板 `+ΔW/c²/COEF` 对应「本振频率高于梳尺」的
假设**（s_beat = −1）。

### 5.4 符号与相关性的关系（重要澄清）

`s_beat`（及由此决定的模板符号）**只影响相关系数 r 的标签正负号**，**不影响**
以下任何相关性结论：

| 量 | 是否受模板取反影响 |
|---|---|
| 相关系数大小 \|r\| | 否 |
| 双侧 p 值 | 否 |
| 跨段合并显著性（Fisher、Stouffer \|z\|） | 否 |
| 符号一致性（12/14 段同号） | 否 |
| r 的标签（+ 或 −） | **是** |

因此「潮汐是否被检出」**完全由显著性决定，与符号无关**。符号方向只决定
「效应朝哪个方向」，属于物理方向解读，不改变检出结论。

## 6. 结论

| 项 | 结果 |
|---|---|
| 拍频→比值系数 | `COEF = 4.2820821632696486e-15`（正） |
| 静态引力红移 | `delta_g = −3.116e-15`（对应 −28.6 m 正高差） |
| 布局 | **Yb 在武汉（WUHN），Sr 在上海（SHAO）** |
| 拍频方向 | **远端**（已确认） |
| 未定符号 | `s_beat = ±1`（梳尺频率高 or 本振频率高） |

**相关性结论（符号无关）**：跨段合并后相关性**极显著存在**（Fisher p≈1.3e-7，
符号无关 Stouffer |z|≈6.33，p≈2.5e-10），加权 |r|≈0.17（弱相关）。这一结论不依赖
s_beat，也不依赖模板符号。

**符号方向（后续补充，仅影响物理方向解读）**：确认「梳尺频率高 还是 本振频率高」
即可定死 s_beat，从而确定潮汐效应是正方向还是反方向——但这只影响「效应朝哪边」，
不影响「效应是否存在」。
