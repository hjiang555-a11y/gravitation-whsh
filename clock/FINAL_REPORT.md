## 摘要

对武汉（WUHN）—上海（SHAO）光钟（Yb/Sr）比对中 14 段无跳点实验的 1550 nm
环外链路拍频，与理论潮汐引力红移模板做相关性分析：

1. **潮汐引力红移效应被检出**：跨段合并后相关性显著（符号无关 Stouffer
   |z| = 4.60，p ≈ 4×10⁻⁶），幅度比 |A| = 0.77 ± 0.18 距 0 约 4.2σ。
2. **幅度比与 1:1 相容**：|A| 距 1 约 1.3σ，95% CI [0.41, 1.12] 包含 1，
   实验幅度约为理论预测的 77%。
3. **信号被链路噪声淹没**：潮汐信号（Δf/f rms ~4.8e-18）比 1200-s 积分后的
   链路噪声（~1.7e-17）小约 3.6 倍，单段必然不显著，仅跨段合并能累加出趋势。

## 1. 物理链路与符号系数

潮汐引力势差 ΔW = W(SHAO) − W(WUHN) 通过广义相对论引力红移改变两地钟频率差：

```text
Δf/f = ΔW / c²
```

### 1.1 拍频 → 比值偏移系数 COEF

从 MATLAB 处理程序（`YbSr_NISTstyle_14bin_full_analysis_20260824.m` 第 917–918 行）
提取：

```text
Dr = coef1156/N1156 × (mean_dm / fref / div20) / den
den = coef1397/N1397 × (N1550 + 7/25 + 1/25)
COEF = 4.2820821632696486e-15    （拍频[Hz] → 比值偏移，正）
```

其中 `fref × div20 = 1e7 × 20 = 200 MHz`，即**光频梳重复频率 f_rep**（用户确认）。
系数自洽性：`N1156 × f_rep = 259.15 THz`（1156.8 nm，Yb 基波）、
`N1550_WH × f_rep = 193.40 THz`（1550.1 nm，武汉传递链路）✅

### 1.2 静态引力红移与站点布局

```text
delta_g = −3.116e-15
ΔW_static = delta_g × c² = −280.05 m²/s²  →  Δh ≈ −28.6 m（正高差）
```

由 `delta_g < 0` 推得 W_Sr < W_Yb，结合地理（上海沿海 ~20 m、武汉内陆 ~50 m）：

> **Yb 钟在武汉（WUHN），Sr 钟在上海（SHAO）。**

### 1.3 潮汐模板符号

潮汐时变下 Sr/Yb 比值偏移：

```text
δ(Sr/Yb) = (δW_Sr − δW_Yb)/c² = (W_SHAO − W_WUHN)/c² = ΔW/c²
拍频潮汐模板 = +ΔW/c² / COEF
```

符号约定详见 [SIGN_COEFFICIENT_ANALYSIS.md](SIGN_COEFFICIENT_ANALYSIS.md)。

## 2. 数据与方法

### 2.1 数据覆盖

| 组 | 状态 |
|---|---|
| 1–5 | 无数据（7 月 Freq_B 文件仅 260705–260707，缺 260628–260704） |
| 6 | 缺前半 4.49 h，可用 10 h |
| 7–13 | 完整 |
| 14 | 缺后半，可用 19 h |

共 **9 段可分析**。

### 2.2 方法（无挑点原则）

1. 按 MATLAB 约定重建均匀 1-s 时间轴（时间戳 ±1 s 抖动，漂移 0）；
2. 套用 MATLAB `exclude_ranges` 手动扣除时段；
3. 剔除偏离中位数 >10 Hz 的跳点；
4. **取最长无跳点连续段**（逐段核验：段内 0 跳点、0 时间断点）；
5. 1200 s 三角（Bartlett）窗口、600 s 步长（50% 重叠）积分；
6. 去均值后计算相关系数 r 与幅度比 A。

## 4. 跨段合并统计（符号无关）

| 检验 | 数值 | 结论 |
|---|---|---|
| 符号一致性 | 8/9 段同号（88.9%） | 二项 p = 0.020 |
| \|r\| Fisher-z 加权平均 | 0.168 | 弱相关 |
| Fisher 合并（双侧 p） | 1.3×10⁻⁴ | 显著 |
| Stouffer 合并（符号无关 \|z\|） | **4.60** | **p = 4×10⁻⁶** |

**相关性结论独立于符号约定**：把模板整体取反，r 翻号，但 |r|、p 值、符号
一致性、合并显著性全部不变。故「统计关联存在」这一结论不依赖任何符号假设。

## 5. 幅度比 A = 实验 / 理论（1:1 检验）

`A = 1` 表示实验完整反映理论潮汐幅度。用非重叠窗口（1200 s，stride=1200 s，
避免 50% 重叠的自由度膨胀）重算，排除离群组 9：

```text
|A| = 0.77 ± 0.18
95% CI = [0.41, 1.12]
距 0 约 4.2σ（检出）
距 1 约 1.3σ（与 1:1 相容）
```

**结论**：

1. **潮汐效应被检出**：|A| 距 0 约 4.2σ，显著非零。
2. **幅度比 ≈ 0.77**：实验幅度约为理论的 77%，点估计偏小 ~23%。
3. **与 1:1 相容**：距 1 仅 1.3σ，95% CI 包含 1，不能拒绝 1:1，但当前信噪比
   也不足以精确确认 1:1。
4. 偏小 ~23% 的可能来源：链路噪声残留、时钟位置/COEF 微调、短段贡献。

## 6. 结论

| 维度 | 结论 |
|---|---|
| 相关性（存在性） | 跨段合并显著（符号无关 Stouffer \|z\|=4.60，p≈4e-6） |
| 相关强度 | 弱（加权 \|r\|≈0.17），潮汐模板解释 ~3% 拍频变异 |
| 幅度比（1:1） | \|A\| = 0.77 ± 0.18，与 1:1 相容（95% CI 含 1） |
| 检出判定 | **潮汐引力红移效应被检出**，幅度接近理论预测 |
| 符号方向 | 唯一未定项 s_beat（梳尺高/本振高），仅影响物理方向，不影响检出 |

### 核心结论

**武汉—上海光钟比对中，潮汐引力红移效应以弱但显著的相关性被检出**
（跨段合并 p≈4×10⁻⁶），幅度比 |A|≈0.77 与理论 1:1 相容（95% CI 含 1）。
信号虽被 1550 nm 链路噪声淹没约 3.6 倍，但跨段合并累加出了真实的、方向一致的
潮汐趋势。
