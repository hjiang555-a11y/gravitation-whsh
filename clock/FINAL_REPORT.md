## 摘要

对武汉（WUHN）—上海（SHAO）光钟（Yb/Sr）比对中 14 段无跳点实验的 1550 nm
环外链路拍频，与理论潮汐引力红移模板做相关性分析：

1. **潮汐引力红移效应被检出**：跨段合并后相关性极显著（符号无关 Stouffer
   |z| = 6.33，p ≈ 2.5×10⁻¹⁰），幅度比 A = −0.52 ± 0.08 距 0 约 6.8σ。
2. **幅度比 ≈ −0.5**：实验幅度约为理论预测的一半，12/14 段方向一致为负。
3. **信号被噪声本底淹没**：潮汐信号（Δf/f rms ~4.8e-18）比 1200-s 积分后的
   噪声本底（~1.7e-17，钟白频率噪声）小约 3.6 倍，单段必然不显著，仅跨段合并
   能累加出趋势。

## 1. 物理链路与符号系数

潮汐引力势差 ΔW = W(SHAO) − W(WUHN) 通过广义相对论引力红移改变两地钟频率差：

```text
Δf/f = ΔW / c²
```

### 1.1 拍频 → 比值偏移系数 COEF

从 MATLAB 处理程序（`YbSr_NISTstyle_14bin_full_analysis_20260824.m` 第 917–918 行）
提取：

```text
Dr = coef1156/N1156 × (mean_dm / fref / div20) / den
den = coef1397/N1397 × (N1550 + 7/25 + 1/25)
COEF = 4.2820821632696486e-15    （拍频[Hz] → 比值偏移，正）
```

其中 `fref × div20 = 1e7 × 20 = 200 MHz`，即**光频梳重复频率 f_rep**（用户确认）。
系数自洽性：`N1156 × f_rep = 259.15 THz`（1156.8 nm，Yb 基波）、
`N1550_WH × f_rep = 193.40 THz`（1550.1 nm，武汉传递链路）✅

### 1.2 静态引力红移与站点布局

```text
delta_g = −3.116e-15
ΔW_static = delta_g × c² = −280.05 m²/s²  →  Δh ≈ −28.6 m（正高差）
```

由 `delta_g < 0` 推得 W_Sr < W_Yb，结合地理（上海沿海 ~20 m、武汉内陆 ~50 m）：

> **Yb 钟在武汉（WUHN），Sr 钟在上海（SHAO）。**

### 1.3 潮汐模板符号

潮汐时变下 Sr/Yb 比值偏移：

```text
δ(Sr/Yb) = (δW_Sr − δW_Yb)/c² = (W_SHAO − W_WUHN)/c² = ΔW/c²
拍频潮汐模板 = +ΔW/c² / COEF
```

符号约定详见 [SIGN_COEFFICIENT_ANALYSIS.md](SIGN_COEFFICIENT_ANALYSIS.md)。

## 2. 数据与方法

### 2.1 数据覆盖

> 更新（2026-09-04）：修复 `batch_analysis.py` 漏加载 6 月 `2606*.txt` 后，
> **14 段全部有数据**（组 6 缺前半 4.49 h、组 14 缺后半，其余完整）。

共 **14 段可分析**。

### 2.2 方法（无挑点原则）

1. 按 MATLAB 约定重建均匀 1-s 时间轴（时间戳 ±1 s 抖动，漂移 0）；
2. 套用 MATLAB `exclude_ranges` 手动扣除时段；
3. 剔除偏离中位数 >10 Hz 的跳点；
4. **取最长无跳点连续段**（逐段核验：段内 0 跳点、0 时间断点）；
5. 1200 s 三角（Bartlett）窗口、600 s 步长（50% 重叠）积分；
6. 去均值后计算相关系数 r 与幅度比 A。

## 4. 跨段合并统计（符号无关）

| 检验 | 数值 | 结论 |
|---|---|---|
| 符号一致性 | 12/14 段同号（85.7%） | 二项双侧 p = 0.013 |
| 加权 r（Fisher-z） | −0.173 | 弱相关 |
| Fisher 合并（双侧 p） | 1.3×10⁻⁷ | 极显著 |
| Stouffer 合并（符号无关 \|z\|） | **6.33** | **p = 2.5×10⁻¹⁰** |

**相关性结论独立于符号约定**：把模板整体取反，r 翻号，但 |r|、p 值、符号
一致性、合并显著性全部不变。故「统计关联存在」这一结论不依赖任何符号假设。

## 5. 幅度比 A = 实验 / 理论（幅度检验）

`A = −1` 表示实验完整反映理论潮汐幅度（方向为负）。对 14 段幅度拟合结果做
精度加权（1/u_A²），排除短窗口离群组 9：

```text
A = −0.53 ± 0.08
距 0 约 6.8σ（检出）
|A| ≈ 0.53（实验幅度约为理论的一半）
```

**结论**：

1. **潮汐效应被检出**：A 距 0 约 6.8σ，显著非零。
2. **幅度比 ≈ −0.5**：实验幅度约为理论预测的一半，且 12/14 段方向一致为负。
3. **信噪比不足**：单段幅度拟合大多不显著（信号 rms ~4.8e-18 被钟白频率噪声
   ~1.7e-17 淹没 ~3.6 倍），幅度比由跨段合并的符号一致性累加得出，点估计
   仍受短段与噪声残留影响。
4. 幅度 <1 的可能来源：链路相位噪声残留、时钟位置/COEF 微调、短段贡献。

## 6. 结论

| 维度 | 结论 |
|---|---|
| 相关性（存在性） | 跨段合并极显著（符号无关 Stouffer \|z\|=6.33，p≈2.5e-10） |
| 相关强度 | 弱（加权 \|r\|≈0.17），潮汐模板解释 ~3% 拍频变异 |
| 幅度比 | A = −0.53 ± 0.08（6.8σ），实验幅度约为理论的一半，12/14 段同负 |
| 检出判定 | **潮汐引力红移效应被检出**，方向一致、部分幅度 |
| 符号方向 | 唯一未定项 s_beat（梳尺高/本振高），仅影响物理方向，不影响检出 |

### 核心结论

**武汉—上海光钟比对中，潮汐引力红移效应以弱但极显著的相关性被检出**
（跨段合并符号无关 Stouffer |z|=6.33，p≈2.5e-10，12/14 段同向），幅度比
A = −0.53±0.08（6.8σ）。
信号虽被噪声本底（钟白频率噪声）淹没约 3.6 倍，但跨段合并累加出了真实的、方向
一致的潮汐趋势。
