## 1. 分析对象与方法

**实测**：武汉—上海光钟比对中 1550 nm 环外链路拍频（FXE_B8，~33.6 MHz），
14 段无跳点实验窗口（`atomic-clock-comp.pdf` 表 1）。

**理论**：本项目计算的潮汐引力势差 ΔW 经引力红移换算为拍频位移
`beat_tide = (ΔW/c²)/COEF`，`COEF = 4.282082163269648e-15`。

**方法**（[segment_analysis/batch_analysis.py](segment_analysis/batch_analysis.py)）：

1. 按 MATLAB 约定重建均匀 1-s 时间轴（时间戳 ±1 s 抖动，漂移为 0）；
2. 套用 MATLAB `exclude_ranges` 手动扣除时段；
3. 剔除偏离中位数 >10 Hz 的跳点；
4. **取剩余有效、1-s 连续数据中的最长连续段**——分析所用的每一段内部
   **严格 0 挑点**（逐段核验：每段内均 0 个 >10 Hz 偏离点、0 个时间断点）；
5. 1200 s 三角（Bartlett）窗口、600 s 步长（50% 重叠）积分；
6. 去均值后计算实测拍频与潮汐模板的 Pearson 相关系数 r。

> **无挑点原则**：若段内有跳点，一律截取最长无跳点连续段分析，绝不带跳点计算。
> 下表「跳点」列为**整段窗口内剔除的跳点数**（用于截取），实际参与分析的
> 最长连续段内为 0 跳点。

> 数据覆盖：组 1–5 已在修复 `batch_analysis.py` 漏加载 6 月 `2606*.txt` 后恢复，
> **14 段全部有数据**。

## 3. 跨段合并统计（符号无关）

| 检验 | 数值 | 结论 |
|---|---|---|
| 符号一致性 | 12/14 段同号（85.7%） | 二项双侧 p = 0.013 |
| 加权 r（Fisher-z） | −0.173 | 弱相关 |
| Fisher 合并（双侧 p） | **p = 1.3×10⁻⁷** | 极显著 |
| Stouffer 合并（符号无关，\|z\|） | **z = 6.33，p = 2.5×10⁻¹⁰** | 极显著 |
| 幅度比 A（精度加权） | **−0.52 ± 0.08** | 距 0 约 6.8σ |

**符号一致性**：14 段中 12 段相关系数同号，远超随机预期（随机情形期望 ~50%，
二项双侧 p = 0.013）。

**合并显著性**：无论 Fisher 法（p=1.3e-7）还是符号无关的 Stouffer 法
（|z|=6.33，p=2.5e-10），跨段合并后相关性都**极显著存在**，且此结论不依赖符号约定。

**相关强度**：加权 |r| ≈ 0.17，属弱相关。即潮汐模板解释了实测拍频变异的
~3%（R² = 0.17² ≈ 0.03），与「信号被链路噪声淹没、仅趋势可辨」一致。

## 4. 为什么单段不显著、合并才显著

潮汐引力红移信号（Δf/f rms ~4.8e-18）比 1200-s 积分后的链路噪声（~1.7e-17）
小约 **3.6 倍**，单段信噪比 ~0.28，任何单段幅度/相关都必然被噪声主导。

但噪声是无符号的，而真实潮汐信号有**确定的时间结构**。跨段合并相当于把
14 段独立的、方向一致的弱信号趋势累加，噪声相互抵消、信号相干叠加，从而把
单段无法分辨的相关性提出来。

| 量 | Δf/f |
|---|---|
| 潮汐信号 rms（段 13） | 4.76e-18 |
| 1-s 拍频噪声 | 1.92e-15（比信号大 ~400 倍） |
| 1200-s 积分后噪声 | 1.73e-17（比信号大 ~3.6 倍） |

## 5. 幅度比 A = 实验 / 理论

「实验是否准确反映引力潮汐影响」由**幅度比 A**衡量：`A = ±1` 表示实验完整反映
理论潮汐幅度（正/反方向）。`r` 与 `A` 的区别：`r = A · σ_tide/σ_noise`，被噪声
稀释；`A` 是幅度比的无偏估计（去均值最小二乘 `A = cov(beat, tide)/var(tide)`）。

对 14 段幅度拟合结果做精度加权（1/u_A²），排除短窗口离群组 9：

```text
A = −0.52 ± 0.08
距 0 约 6.8σ（检出）
|A| ≈ 0.53（实验幅度约为理论的一半）
```

**结论**：

1. **潮汐效应被检出**：A 距 0 约 6.8σ，显著非零。
2. **幅度比 ≈ −0.5**：实验幅度约为理论的一半，且 12/14 段方向一致为负。
3. **信噪比不足**：单段幅度拟合大多不显著，幅度比由跨段符号一致性累加得出，
   点估计仍受短段与噪声残留影响。
4. 幅度 <1 的可能来源：链路噪声残留、时钟位置/COEF 微调、或短段贡献。

> 系数本身（COEF = 4.28e-15）是拍频→比值偏移的换算系数，**不是幅度比对的对象**。
> 「幅度比」指 A = 实验/理论 的幅度比例，两者概念不同。

## 6. 结论

1. **单段**：14 段中仅 5 段（组 1/3/5/10/14）相关性个别显著，其余被链路噪声淹没。
2. **跨段合并**：相关性**极显著存在**（Fisher p=1.3e-7；符号无关 Stouffer
   |z|=6.33，p=2.5e-10），且**不依赖符号约定**。
3. **相关强度**：弱相关（加权 |r| ≈ 0.17），潮汐模板解释 ~3% 的拍频变异，
   符合「趋势方向一致、幅度被噪声稀释」的预期。
4. **幅度比**：A = −0.52 ± 0.08，距 0 约 6.8σ（检出），实验幅度约为理论一半。
5. **符号方向**：12/14 段同号（当前约定下为负），但正负号的物理含义需待 Yb/Sr
   钟部署站点与拍频符号约定确认后另行解读（见 §7，本报告不展开）。
