# 光钟比对潮汐引力红移 — 相关性分析报告

## 1. 分析对象与方法

**实测**：武汉—上海光钟比对中 1550 nm 环外链路拍频（FXE_B8，~33.6 MHz），
17 段无跳点实验窗口（`潮汐修正后的比值计算.pdf`，窗口时间为**北京时间 UTC+8**，已确认）。

**理论**：专业人士提供的 30 秒间隔潮汐「综合差」ΔW 经引力红移换算为拍频位移
`beat_tide = (ΔW/c²)/COEF`，`COEF = 4.282082163269648e-15`，潮汐数据为 **UTC**。
比对前把拍频窗口 −8 h 对齐到 UTC 潮汐时间轴。

**方法**（[segment_analysis/batch_analysis.py](segment_analysis/batch_analysis.py)）：

1. 按 MATLAB 约定重建均匀 1-s 时间轴（时间戳 ±1 s 抖动，漂移为 0）；
2. 套用 MATLAB `exclude_ranges` 手动扣除时段；
3. 剔除偏离中位数 >10 Hz 的跳点；
4. **取剩余有效、1-s 连续数据中的最长连续段**——分析所用的每一段内部
   **严格 0 挑点**（逐段核验：每段内均 0 个 >10 Hz 偏离点、0 个时间断点）；
5. 1200 s 三角（Bartlett）窗口、600 s 步长（50% 重叠）积分——**拍频与潮汐模板
   用同一窗口投影**（潮汐先建 1-s 序列再同窗积分，非窗口中心点采样），保证相关
   系数评估公平；
6. 去均值后计算实测拍频与潮汐模板的 Pearson 相关系数 r。

> **无挑点原则**：若段内有跳点，一律截取最长无跳点连续段分析，绝不带跳点计算。
> 下表「跳点」列为**整段窗口内剔除的跳点数**（用于截取），实际参与分析的
> 最长连续段内为 0 跳点。

> 数据覆盖：**17 段全部有数据**——第 15/16/17 段为 8 月 21–26 日新增，对应
> `260820`–`260826` 原始拍频文件，25 个 `Freq_B_2_*.txt` 覆盖 17 段无缺口。

## 3. 跨段合并统计（符号无关）

| 检验 | 数值 | 结论 |
|---|---|---|
| 符号一致性 | 14/17 段同号（82.4%） | 二项双侧 p = 0.0127 |
| 加权 r（Fisher-z） | −0.127 | 弱相关 |
| Fisher 合并（双侧 p） | **p = 2.2×10⁻⁶** | 极显著 |
| Stouffer 合并（符号无关，\|z\|） | **z = 5.87，p = 4.3×10⁻⁹** | 极显著 |
| 幅度比 A（精度加权） | **−0.45 ± 0.07** | 距 0 约 6.4σ |

**符号一致性**：17 段中 14 段相关系数同号，远超随机预期（随机情形期望 ~50%，
二项双侧 p = 0.0127）。

**合并显著性**：无论 Fisher 法（p=2.2e-6）还是符号无关的 Stouffer 法
（|z|=5.87，p=4.3e-9），跨段合并后相关性都**极显著存在**，且此结论不依赖符号约定。

**相关强度**：加权 |r| ≈ 0.13，属弱相关。即潮汐数据解释了实测拍频变异的
~1.7%（R² = 0.13² ≈ 0.017），与「信号被噪声本底淹没、仅趋势可辨」一致。
新增 3 段（15/16/17）的 r 绝对值很小（|r| ≤ 0.03），稀释了合并 r，但符号一致性
（14/17 同号）与合并显著性仍稳健。

## 4. 为什么单段不显著、合并才显著

潮汐引力红移信号（Δf/f rms ~4.8e-18）比 1200-s 积分后的噪声本底（~1.7e-17）
小约 **3.6 倍**，单段信噪比 ~0.28，任何单段幅度/相关都必然被噪声主导。
（噪声模型经确认：光纤链路为白相位噪声 σ∝1/τ，钟为白频率噪声 σ∝1/√τ；真正
的检测本底是钟白频率噪声，链路白相位噪声在潮汐超低频段贡献可忽略。）

但噪声是无符号的，而真实潮汐信号有**确定的时间结构**。跨段合并相当于把
17 段独立的、方向一致的弱信号趋势累加，噪声相互抵消、信号相干叠加，从而把
单段无法分辨的相关性提出来。

| 量 | Δf/f |
|---|---|
| 潮汐信号 rms（段 13） | 4.76e-18 |
| 1-s 拍频噪声（链路白相位） | 1.92e-15（比信号大 ~400 倍） |
| 1200-s 积分后噪声（钟白频率本底） | 1.73e-17（比信号大 ~3.6 倍） |

## 5. 幅度比 A = 实验 / 理论

「实验是否准确反映引力潮汐影响」由**幅度比 A**衡量：`A = ±1` 表示实验完整反映
理论潮汐幅度（正/反方向）。`r` 与 `A` 的区别：`r = A · σ_tide/σ_noise`，被噪声
稀释；`A` 是幅度比的无偏估计（去均值最小二乘 `A = cov(beat, tide)/var(tide)`）。

对 17 段幅度拟合结果做精度加权（1/u_A²），排除短窗口离群组 9：

```text
A = −0.45 ± 0.07
距 0 约 6.4σ（检出）
|A| ≈ 0.45（实验幅度约为理论的一半）
```

**结论**：

1. **潮汐效应被检出**：A 距 0 约 6.4σ，显著非零。
2. **幅度比 ≈ −0.5**：实验幅度约为理论的一半，且 14/17 段方向一致为负。
3. **信噪比不足**：单段幅度拟合大多不显著，幅度比由跨段符号一致性累加得出，
   点估计仍受短段与噪声残留影响。
4. 幅度 <1 的可能来源：链路相位噪声残留、时钟位置/COEF 微调、或短段贡献。

> 系数本身（COEF = 4.28e-15）是拍频→比值偏移的换算系数，**不是幅度比对的对象**。
> 「幅度比」指 A = 实验/理论 的幅度比例，两者概念不同。

## 6. 结论

1. **单段**：17 段中仅 5 段（组 1/3/5/10/14）相关性个别显著，其余被噪声本底淹没。
2. **跨段合并**：相关性**极显著存在**（Fisher p=2.2e-6；符号无关 Stouffer
   |z|=5.87，p=4.3e-9），且**不依赖符号约定**。
3. **相关强度**：弱相关（加权 |r| ≈ 0.13），潮汐数据解释 ~1.7% 的拍频变异，
   符合「趋势方向一致、幅度被噪声稀释」的预期。
4. **幅度比**：A = −0.45 ± 0.07，距 0 约 6.4σ（检出），实验幅度约为理论一半。
5. **符号方向**：14/17 段同号（当前约定下为负），但正负号的物理含义需待 Yb/Sr
   钟部署站点与拍频符号约定确认后另行解读（见 §7，本报告不展开）。
