# Overleaf upload package — paper/rev2 (rebuilt candidate)

This folder is ready to upload to Overleaf as-is. It contains the rebuilt
candidate manuscript (`paper/rev2/` in the repository), based on the frozen
phase-one audit result layer: 16-segment primary membership, the
time-varying-redshift term carried as an uncertainty item, Nature-style
layout (Methods after the reference list).

## Contents

```
main.tex          # manuscript entry point (Nature-style section order)
sections/         # abstract, introduction, results, discussion, methods, appendix
generated/        # numbers.tex + segment_table.tex (machine-generated; do not edit);
                  # numbers.json + numbers_manifest.json carry provenance only
refs.bib          # bibliography
figs/             # figures (vector PDF)
  fig1_network.pdf    # network schematic
  fig2_campaign.pdf   # campaign stages + per-segment ratio deviations
  fig3_compare.pdf    # comparison with published ratios + uncertainty budget
```

## How to upload

1. Download this folder (or the zip `paper/overleaf-rev2-upload.zip`).
2. On Overleaf: **New Project → Upload Project**, then drop the zip.
3. Set the main document to `main.tex` (Overleaf usually detects it).
4. Compiler: **pdfLaTeX** (default).

## Build

```
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

Required packages: `fontenc`, `inputenc`, `amsmath`, `amssymb`,
`graphicx`, `booktabs`, `geometry`, `natbib`, `hyperref`, `siunitx`,
`xspace` (all standard in TeX Live / Overleaf).

## Notes

- **Do not hand-edit `generated/numbers.tex` or `generated/segment_table.tex`.**
  Every number in the manuscript is a macro generated by
  `paper/rev2/tools/build_numbers.py` from the frozen manifest
  (`results/audit-v1/verified/manifest.json`); provenance is listed in
  `paper/rev2/generated/numbers_manifest.json`. To regenerate, run from the
  repository root:

  ```
  cd paper/rev2
  python3 tools/build_numbers.py          # regenerate
  python3 tools/build_numbers.py --check  # verify the four outputs are current
  ```

- The author line is the placeholder `xxxxx`; the author list,
  affiliations and back-matter statements are to be supplied by the
  collaboration before submission.
- Title (as specified in review, ~100 characters): "An inter-city Sr/Yb
  optical clock comparison at the 2.1x10^-18 uncertainty over a 1,350 km
  fibre link"; still above Nature's 75-character guideline.
- Abstract replaced with the specified text (2026-10-09); 177 words,
  numbers macro-backed. Main text length ~1,534 words (summary +
  Introduction + Results + Discussion and outlook) against the
  ~2,500-word anchor for a typical 6-page Nature Article; the full
  length-vs-format review is in `paper/rev2/REVIEW_NOTES.md` (repository).
- This package is synced from `paper/rev2/` by
  `paper/rev2/tools/sync_overleaf.sh`; one-shot verification is
  `paper/rev2/tools/check.sh`.
