## 摘要

1. **实验能力定位**：本实验为武汉 Yb 与上海 Sr 光钟经 1550 nm 光纤链路的远程比对，
   17 段、总有效时长 `T_valid = 1 008 912 s`（≈ 11.68 天，占空比 20.1%，观测跨度
   5.0×10⁶ s ≈ 58 天）。Yb/Sr 比值在 `10⁻¹⁸` 量级重建。

2. **可探测的物理模型**（对标 3104 及 PRL/Nature 文献）：主要覆盖
   - **超轻玻色暗物质**（标量/赝标量，与光子、电子、胶子耦合）——本实验**唯一有直接
     灵敏度的通道**是通过精细结构常数 `α`（耦合 `d_e`）；
   - **基本常数漂移**（`α`、`μ = m_p/m_e`）——本实验对 `α` 有灵敏度，对 `μ` **零**灵敏度；
   - **引力红移 / 广义相对论 / 局部位置不变性（LPI）**——本实验已在潮汐引力红移上实现
     6.4σ 的检出，是天然且已完成的检验通道；
   - **拓扑缺陷暗物质**（畴壁、孤子）——可在光纤网络框架下搜索，但需专用事件分析。

3. **关键物理事实（硬约束）**：本实验的 Yb/Sr 比值**只对 `α` 敏感，对 `m_e/μ` 完全不敏感**。
   相对论灵敏度系数差 `ΔK_α^{Yb/Sr} = |K_Yb − K_Sr| = |0.31 − 0.06| = 0.25`；
   而对电子质量/质量比的灵敏度系数差 `ΔK_μ^{Yb/Sr} = 0`（两个都是光学电子跃迁）。
   这直接决定了探测能力的形状：**能探 `d_e`/`α`，不能探 `m_e`/`μ`**（除非法引入光学-微波组合）。

4. **量级估算结果**（illustrative）：以库内逐段 `u_i` 反推白噪声系数
   `h_0 = 2σ_y²(T_i)T_i`，均值 `h_0 = 3.9×10⁻³¹`（等效 1 秒稳定度 `σ_y(1s) ≈ 4.4×10⁻¹⁶`，
   与 BACON 的 Yb/Sr `3.1×10⁻¹⁶` 同量级、仅差 1.4 倍）。在有效积分时间 `T_valid` 上的
   相干正弦幅度探测限
   `δ_R ≈ 8.8×10⁻¹⁹`（`√(2h_0/T_valid)`）。由此经 BACON 转换
   `d_e = 4.2×10³⁰ δ_R m_φ/ΔK`（`m_φ` 单位 eV）得
   - 带低端（`m_φ ≈ 4.1×10⁻²³ eV`）：`d_e ~ 6×10⁻¹⁰`（乘随机振幅修正 ×3 后 `~1.8×10⁻⁹`）；
   - 带高端（`m_φ ≈ 4.1×10⁻¹⁷ eV`）：`d_e ~ 6×10⁻⁴`。
   这些是**量级估算**，不是约束声明（§4.4、§6）。

5. **与 BACON 的相对定位**：本实验的 `δ_R` 探测限（`8.8×10⁻¹⁹`）**优于** BACON 的 Yb/Sr
   单比值探测限（`~1.5×10⁻¹⁸`），原因是有效积分时间更长（`1.0×10⁶ s` vs `1.7×10⁵ s`）；
   但 `ΔK_α = 0.25` 远小于最优对（`Yb⁺E3/Sr` 的 `ΔK = 6.01`、`Al⁺/Hg⁺` 的 `2.95`），
   在 `d_e` 灵敏度上天然吃亏约 12–24 倍（§4.3）。

6. **诚实边界**：库内 `u_i` 不可靠、占空比低、噪声非严格白噪声、以及 `A=-0.54` 的 DC 假设
   等问题，使上述 `d_e` 数字只能作方法演示。**若未来要做正式暗物质约束**，须先解决
   §6 列出的全部前提。

## 2. 文献调研：光钟网络对 BSM 物理的探测（对标 3104）

本节综述与本实验可比的、以光钟/原子钟为探针的高影响力物理模型搜索。**本实验是 Yb/Sr 光纤
比对**，因此特别关注使用光学频率比（同物种或异物种）的文献。

### 2.1 超轻玻色暗物质（scalar / pseudoscalar DM）

**框架（Kostelecký-type 宇宙标量场）**：超轻玻色暗物质粒子质量 `m_φ`（亦即康普顿频率
`ω_C = m_φc²/ħ`）以相干振荡的经典场 `φ(t) = φ_0 cos(ω_C t + θ)` 形式存在，通过与标准模型场
耦合，使基本常数（`α`、`m_e`、`m_p` 等）产生表观振荡。原子钟跃迁频率依赖这些常数，因此
频率比 `ν₁/ν₂` 会随 `φ(t)` 振荡。测量方程（3104）：

```
(R(t) − R₀)/R₀ = δ_R sin(ω_C t + θ)
```

其中 `δ_R` 为比值振荡的相对幅度。对精细结构常数 `α` 的灵敏度由
**灵敏度系数差** `ΔK = |K₁ − K₂|` 给出：

```
δ_R = ΔK · (δα/α)
```

BACON 使用的系数（Safronova et al., RMP 90, 025008 (2018)）：

| 物种 | 跃迁 | `K_α` |
|---|---|---|
| Al⁺ | ¹S₀–³P₀ | 0.008 |
| Sr | ¹S₀–³P₀ | **0.06** |
| Yb | ¹S₀–³P₀ | **0.31** |
| Hg⁺ | ²S₁/₂–²D₅/₂ | −2.9 |

**本实验的 `ΔK_α`**：

```
ΔK_α^{Yb/Sr} = |K_Yb − K_Sr| = |0.31 − 0.06| = 0.25
```

> 该值经文献交叉确认（Marti et al., arXiv:1811.05885 亦给出 `ΔK_{Yb,Sr}^α = 0.25`）。

**耦合到光子张量的参数 `d_e`**：3104 采用的经验转换（Nature 591, 564 (2021)，
"Dark-matter constraints" 节）：

```
d_e = 4.2×10³⁰ · δ_R · m_φ / ΔK        （m_φ 单位 eV）
```

该式已归一化到引力强度耦合，假定局域暗物质密度 `ρ_DM = 0.4 GeV/cm³`，并已包含对
暗物质场随机振幅涨落的**统一重标因子 3.0**（Centers et al., Nat. Commun. 12, 7321 (2021)）。
等价的现代写法（Filzinger et al., PRL 130, 253001 (2023)）：

```
|d_e| = (ω A_ω / k_α) · √(c² / 8πGρ_DM)
```

**dilaton 耦合尺度**（Arvanitaki, Huang, Van Tilburg, PRD 91, 015015 (2015)）：

```
Λ_γ = M_Pl / (√(4π) d_e),    M_Pl = 1.22×10¹⁹ GeV
```

|---|---|---|---|
| **Beloy et al. 2021 (BACON)** `3104.pdf` | Al⁺/Sr/Yb 网络 | `d_e`（光子）、`m_e` | 比值精度 ≤8×10⁻¹⁸；`d_e` 排除区横跨 `10⁻²³–10⁻¹⁸ eV`，较前约束改善至多 10 倍 |
| Wcisło et al. 2018, Sci. Adv. 4, eaau4869 | Yb+Sr 四实验室三洲网络 | `α`、瞬变 | `|δα/α| < 1.6×10⁻¹⁶`（改善 2 个量级），利用原子-腔 `α` 敏感度差 |

### 2.2 基本常数漂移

原子钟频率比对是约束 `α` 和 `μ = m_p/m_e` 随时间/空间变化的核心手段。关键结构事实
（Sherrill et al. 2023；Huntemann et al. 2014）：

- **纯光学-光学比值**（如 Yb/Sr）：只对 `α` 敏感，`ΔK_μ = 0`。
- **光学-微波（超精细）比值**（如 Sr/Cs、Yb/Cs）：`ΔK_μ = 1.00`，可约束 `m_e/μ`。
- **超精细-超精细比值**（如 Rb/Cs）：`ΔK_μ = 0`（相互抵消）。

**本实验的推论**：Yb/Sr 比值**不能**直接约束 `μ` 或 `m_e`；报告任何来自 Yb/Sr 的 `m_e`
灵敏度都是错误的。若未来要与 Cs/Rb 钟联合，才能打开 `m_e` 通道。

代表文献：Godun et al. 2014, PRL 113, 210801（Yb⁺ E2/E3）；Huntemann et al. 2014,
PRL 113, 210802（Yb⁺/Cs，`m_p/m_e`）；Lange et al. 2021, PRL 126, 011102（LPI 违反）。

## 3. 本实验的物理通道：能探什么、不能探什么

### 3.1 灵敏度系数矩阵

| 通道 | 本实验(Yb/Sr)灵敏度系数差 | 可否探测 | 说明 |
|---|---|---|---|
| `α` / 光子耦合 `d_e` | `ΔK_α = 0.25` | ✅ 可 | 本报告主通道 |
| `m_e` / `μ` | `ΔK_μ = 0` | ❌ 不可 | 两个都是光学跃迁 |
| 引力红移 `ΔW/c²` | 直接敏感 | ✅ 已检 | 潮汐信号 6.4σ |
| 拓扑缺陷 | 网络敏感 | ⚠️ 需专用分析 | 占空比低 |
| Lorentz / LPI | 需专用组合 | ⚠️ 部分 | 单比值能力有限 |

### 3.2 为什么 Yb/Sr 是最优与最劣之间的折中

最优 `ΔK_α` 对（`Yb⁺E3/Yb⁺E2` 的 6.95、`Yb⁺E3/Sr` 的 6.01、`Al⁺/Hg⁺` 的 2.95）远超
Yb/Sr 的 0.25。但 Yb/Sr 的优势在于：**两个都是高稳定度光晶格钟**，可实现极高统计精度，
且在较高质量端（`m_φ ≳ 10⁻¹⁸ eV`）有竞争力（BACON 的结论）。

## 4. 定量量级估算（illustrative）

> **本节所有数字均为量级估算，不可作为约束引用。** 全部由
> `paper/physics_analysis/sensitivity_estimate.py` 计算（输入为库内逐段 `u_i`），
> 结果见 `sensitivity_estimates.csv` 与 `sensitivity_summary.json`。

### 4.1 方法：从逐段稳定度到振幅探测限

对白频噪声（WFM），`σ_y²(τ) = h_0/(2τ)`，故逐段可反推白噪声系数

```
h_0 = 2 · σ_y²(T_i) · T_i
```

（注意：**不是** `σ_y·√T_i`。）对相干正弦信号的 1σ 幅度探测限（`T_eff` 为有效积分时间）：

```
δ_R ≈ √(2 h_0 / T_eff)  ≈ √2 · σ_y(T_eff)
```

这是一般结果 `δ_R = √(S_y(f₀)/T_eff)` 在 WFM（`S_y` 平）下的特例。**对碎片化数据必须用
总有效时间 `T_valid`，而非墙钟跨度 `T_obs`**（两者差 `√(T_obs/T_valid) = 1/√D ≈ 2.2`）。
在 BACON 频段内 `τ_c ≫ T_valid`，场跨整个观测相干，故可用单一正弦拟合。

### 4.2 逐段与合并结果

逐段 `h_0` 与自身时长上的 `δ_R`（完整表见 `sensitivity_estimates.csv`）：

| 段 | `T_i` (s) | `σ_y(T_i)` | `h_0` | `δ_R` (段内) |
|---|---|---|---|---|
| 5 | 19 532 | 6.55×10⁻¹⁸ | 1.67×10⁻³⁰ | 1.31×10⁻¹⁷ |
| 16 | 147 640 | 3.54×10⁻¹⁹ | 3.70×10⁻³² | 7.08×10⁻¹⁹ |
| … | … | … | … | … |
| 均值 | — | — | **3.87×10⁻³¹** | — |

**合并**：

| 方法 | `δ_R` 探测限 |
|---|---|
| `h_0` 均值 @ `T_valid`（主）| **8.76×10⁻¹⁹** |
| 逐段逆方差合并（交叉验证）| 4.55×10⁻¹⁹ |

等价的 1 秒稳定度：`σ_y(1s) ≈ √(h_0/2) = 4.4×10⁻¹⁶`——与 BACON 的 Yb/Sr
`σ₀ = 3.1×10⁻¹⁶` 同量级（仅差 1.4 倍）。这证明本实验的**统计潜力**与 BACON 相当。

### 4.3 转换为 `d_e` 与 `Λ_γ`

BACON 频段（`1/(20T_max) < f < 1/100 s`）对应
`m_φ ∈ [4.1×10⁻²³, 4.1×10⁻¹⁷] eV`。以主 `δ_R = 8.76×10⁻¹⁹`：

| 位置 | `m_φ` (eV) | `d_e` | 乘随机修正 ×3 | `Λ_γ` (GeV) |
|---|---|---|---|---|
| 带低端 | 4.1×10⁻²³ | 6.1×10⁻¹⁰ | 1.8×10⁻⁹ | 5.7×10²⁷ |
| 带高端 | 4.1×10⁻¹⁷ | 6.1×10⁻⁴ | 1.8×10⁻³ | — |

> **量级解读**：由于 `δ_R` 探测限在频段内**平坦**，而 `d_e ∝ δ_R·m_φ`，故本实验的
> `d_e` 探测限**随质量线性上升**（低频端最好、高频端最差）。这与 BACON 图中曲线在两端的
> 形态差异，根源在于 BACON 使用频率分辨的噪声 PSD（含 flicker 段），而本估算采用单一
> 白噪声系数。这里应把线性上升读作**方法学产物**，不是物理断言。

### 4.4 与 BACON 的相对定位

| 量 | 本实验（估算）| BACON Yb/Sr |
|---|---|---|
| `δ_R` 探测限 | 8.8×10⁻¹⁹ | ~1.5×10⁻¹⁸ |
| 有效积分时间 | 1.0×10⁶ s | 1.7×10⁵ s |
| `ΔK_α` | 0.25 | 0.25（同物种对）|
| 1 秒稳定度 | 4.4×10⁻¹⁶ | 3.1×10⁻¹⁶ |

本实验的 `δ_R` 探测限**优于** BACON 的 Yb/Sr 单项，纯粹因为积分时间更长；
但由于 `ΔK` 相同（同为 Yb/Sr），其 `d_e` 灵敏度对 BACON 的 Yb/Sr 通道大致可比，
而远不及 `Yb⁺E3/Sr`（`ΔK=6.01`）等最优对。

## 6. 局限与不可声明项（MANDATORY）

以下每一条都限制本报告定量结论的效力，**任何引用必须附带这些前提**：

1. **`u_i` 不可靠**：逐段统计不确定度由 OADEV 外推（128–T/4 s）得到，flicker 地板使
   全体段系统性低估约 30–40%，叠加段 5/6/16 异常（`u_i` 极差 ~18 倍）。本报告的
   `h_0`、`δ_R`、`d_e` 全部继承此偏差 → **仅作方法演示**。

2. **占空比与碎片化**：占空比 20.1%，且数据集中在 6–7 月与 8 月两簇（中间有 ~1 月空档）。
   相干正弦拟合的适用性依赖 `τ_c ≫ T_obs`，本估算已假设成立并采用 `T_valid`；
   但严格处理需按频率分辨的 PSD，并考虑空档对相位相干的影响。

3. **噪声非严格白噪声**：库内已指出拍频在 `τ ≳ 4096 s` 出现 flicker 地板（真实噪声地板，
   非潮汐）。用单一 `h_0` 外推是简化。

4. **未传播系统项**：本估算未传播系数、潮汐模型、系统项不确定度；未做 WLS 或总不确定度。
   OADEV 与样本标准差**不是 SEM**。

5. **`d_e` 转换的前提**：BACON 的 4.2×10³⁰ 因子假定 `ρ_DM = 0.4 GeV/cm³`、引力强度归一化、
   随机振幅重标 3.0；改变这些假设会整体平移 `d_e` 线。

6. **质量依赖形态为方法学产物**：`d_e ∝ δ_R·m_φ` 的线性上升来自「平坦 δ_R」简化，
   真实分析（频率分辨噪声）会不同；不可据此断言「高频端更差」的物理结论。

7. **`m_e/μ` 通道不存在**：Yb/Sr 对该通道零灵敏度（§2.2），本报告未也**不应**给出
   任何 `m_e` 约束。

8. **`A=-0.54` 的 DC 假设**：潮汐修正依赖历史去均值波形的幅度用于未去均值模板，是额外假设
   （`docs/METHODOLOGY.md §9.6`），与 BSM 灵敏度无关但影响同类拟合的方法论。

> **一句话**：本报告证明本实验**有潜力**在 `d_e`/`α` 与 GR 通道做物理，但**当前**只能给出
> 量级估算，**不能**给出任何排除线。

## 7. 结论与后续建议

1. **探测能力的物理形状由灵敏度系数决定**：本实验 （Yb/Sr，`ΔK_α=0.25`）**可探** `α`/光子
   耦合 `d_e`、引力红移/GR/LPI；**不可探** `m_e`/`μ`（`ΔK_μ=0`）。

2. **量级估算**：`δ_R ≈ 8.8×10⁻¹⁹`，对应 `d_e ~ 6×10⁻¹⁰`（低端，×3 后 `1.8×10⁻⁹`）
   至 `6×10⁻⁴`（高端），`Λ_γ ~ 5.7×10²⁷ GeV`（低端）。**均为 illustrative，非约束。**

3. **已实现的物理**：潮汐引力红移 6.4σ 检出——这是本实验当前最扎实的物理结果。

4. **后续建议（优先级）**：
   - **(P0) 修复 `u_i`**：重做 OADEV 外推，纳入 flicker 地板，复核段 5/6/16；这是任何
     正式 DM 约束的前提。
   - **(P1) 频率分辨分析**：用真实噪声 PSD（含 flicker）替代单一 `h_0`，做 BACON 式
     正弦扫描拟合，输出频率分辨的 `δ_R(f)` 与 `d_e(m_φ)` 曲线。
   - **(P2) 考虑联合**：与 Cs/Rb 钟数据联合以打开 `m_e/μ` 通道（`ΔK_μ=1`）。
   - **(P3) 拓扑缺陷分析**：为畴壁/瞬变建立专用事件率分析（受占空比限制）。
