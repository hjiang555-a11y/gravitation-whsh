# Overleaf upload package — paper/rev2 (version 2, current)

This folder is ready to upload to Overleaf as-is. It is the **current**
package for the rebuilt candidate manuscript (`paper/rev2/`); the earlier
package `paper/overleaf-rev2/` is kept as a frozen snapshot and is no
longer updated.

## Contents

```
main.tex          # manuscript entry point (Nature-style section order)
sections/         # abstract, introduction, results, discussion, methods, appendix
generated/        # numbers.tex + segment_table.tex (machine-generated; do not edit);
                  # numbers.json + numbers_manifest.json carry provenance only
refs.bib          # bibliography
figs/             # figures (vector PDF)
  fig1_network.pdf    # network schematic
  fig2_campaign.pdf   # campaign stages + per-segment ratio deviations
  fig3_compare.pdf    # comparison with published ratios + uncertainty budget
```

## How to upload

1. Download this folder (or the zip `paper/overleaf-rev2-v2-upload.zip`).
2. On Overleaf: **New Project → Upload Project**, then drop the zip.
3. Set the main document to `main.tex` (Overleaf usually detects it).
4. Compiler: **pdfLaTeX** (default).

## Build

```
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Notes

  Every number in the manuscript is a macro generated by
  `paper/rev2/tools/build_numbers.py` from the frozen manifest; provenance is
  listed in `paper/rev2/generated/numbers_manifest.json`. Regenerate with
  `cd paper/rev2 && python3 tools/build_numbers.py` (verify: `--check`).
- The author line is the placeholder `xxxxx`; the author list and
  affiliations are to be supplied by the collaboration before submission.
- This version (v2) incorporates the author's second revision (title
  "An intercity Yb/Sr optical clock comparison...", Introduction
  restructured, BACON-2021 cited in the dark-matter sentence) and the
  rewritten-and-refined Results 2.1: concise network description (combs
  self-referenced and locked to the local clocks; link on a commercial
  telecom network used non-exclusively; carrier on the ITU-T 100 GHz
  DWDM channel C34, 1550.12 nm, transmitted Shanghai to Wuhan;
  extension of the field-deployed link in ref. [15]; fixed
  factor-of-two frequency relations; recorded out-of-loop beat with
  F_1550 normalization).
- Title is 99 characters (Nature guideline: 75); main text ~1,707 words
  (~68.3% of the 2,500-word 6-page anchor). Metrics: `paper/rev2/REVIEW_NOTES.md`.
