## 摘要

对武汉（WUHN）—上海（SHAO）Yb/Sr 光钟比对中的 17 段无跳点实验，按实验方
MATLAB 程序的逐段比值公式，从 1550 nm 环外链路拍频逐段计算 Yb/Sr 钟比值
偏差 `y_i = R_i/R_ref − 1`，并与理论潮汐引力红移数据做整体相关性分析：

1. **钟比值中心值**：`R_ref = 1.207 507 039 343 337 7209`，与实验方报告
   WLS 中心值 `1.207 507 039 343 337 7213(23)` 仅差 **−0.38 × 10⁻¹⁸**，
   远小于其统计不确定度（u_stat = 4.76 × 10⁻¹⁹）与总不确定度
   （u = 1.90 × 10⁻¹⁸）。逐段 y_i 分布在 **−4.6 ~ +6.6 × 10⁻¹⁸**。
2. **整体相关性**：17 段 y_i 与会话潮汐频移 Δf/f 呈显著正相关，
   **Pearson r = +0.515（p = 0.034）**，Spearman ρ = +0.510（p = 0.037）。
3. **整体均值与修正量**：y_i 的时长加权整体均值 = **−0.408 × 10⁻¹⁸**；
   整体潮汐修正量（时长加权 Δf/f）= **−0.365 × 10⁻¹⁸**，两者同量级同符号。

## 1. 实验与数据

### 1.1 物理链路

潮汐引力势差 `ΔW = W(WUHN) − W(SHAO)` 通过广义相对论引力红移改变两地光钟
频率差：

```text
Δf/f = ΔW / c²
```

武汉—上海两地的站位布局由静态引力红移 `delta_g = −3.116×10⁻¹⁵` 推出：

```text
ΔW_static = delta_g × c² = −280.05 m²/s²  →  Δh ≈ −28.6 m
```

由 `delta_g < 0` 推得 `W_Sr < W_Yb`，结合地理（上海沿海 ~20 m、武汉内陆
~50 m）：**Yb 钟在武汉（WUHN），Sr 钟在上海（SHAO）**。

### 1.2 拍频 → 比值偏移的系数

从 MATLAB 处理程序（第 917–918 行）提取逐段 `Dr` 公式：

```text
Dr      = coef1156/N1156 × (mean_dm / fref / div20) / den
den     = coef1397/N1397 × (N1550 + 7/25 + 1/25)
coef1397 = (1 + shift_a)/2         （Sr 端系统频移修正）
coef1156 = (1 + b_Yb)/2            （Yb 端固定频移修正，b_Yb = −1.7×10⁻¹⁸）
```

拍频 `mean_dm` 是相对全局中位数 `m` 的偏差（Hz），`fref × div20 = 200 MHz`
为光频梳重复频率。逐段钟比值 `R_bin` 由下式重建：

```text
ratio_base_k = coef1156/N1156 × NN / (coef1397_k/N1397 × NN2)
SrYb_raw     = ratio_base_k + Dr
YbSr_raw     = 1 / SrYb_raw
R_bin_YbSr   = YbSr_raw × (1 + delta_g)
```

### 2.1 中心值与精度

```text
R_ref（段 1 Yb/Sr）= 1.207507039343337720916362441013879421720577...
```

| 参考 | 值 | 与 R_ref 差（×10⁻¹⁸） |
|---|---|---|
| 本报告 R_ref | 1.2075070393433377209… | — |
| 实验方 WLS | 1.2075070393433377213(23) | −0.38 |

| 欧洲网络（Pizzocaro 2026） | 1.207507039343337718(32) | +2.92 |

> **精度说明**：钟比值 R ≈ 1.2，逐段 y_i 差异在 **10⁻¹⁸** 量级（第 16–18 位
> 有效数字），IEEE-754 双精度（相对精度 ~2.2×10⁻¹⁶，在 R~1.2 上绝对 ~2.6×10⁻¹⁶
> ≈ 260×10⁻¹⁸）会完全淹没该差异。本报告镜像 MATLAB 程序的 `vpa(...,80)`，
> 采用 Python `decimal` 80 位算术，将段间差异保留至 **10⁻²⁰** 量级。

## 3. 潮汐修正

专业人士提供的 30 秒间隔潮汐「综合差」（固体潮 + 海潮），方向为
**武汉 − 上海**（`ΔW = W(WUHN) − W(SHAO)`）。逐段取段均值 `ΔW`，换算为
潮汐引力红移频移：

```text
Δf/f = ΔW / c²
```

![会话潮汐引力红移频移](../clock/clock_tidal_shift.png)

潮汐周期远长于计数器的可能时间错位（最剧烈变化率 ~8.7×10⁻²²/s），故 30-s
数据与 1-s 拍频经线性插值逐点对齐后，时间错位影响可忽略。

## 4. 整体相关性分析

将 17 段钟比值偏差 y_i 与会话潮汐频移 Δf/f 做相关（点大小 ∝ 段有效时长）：

![钟比值偏差 vs 会话潮汐频移](correlation_reanalysis.png)

### 4.1 整体相关性

| 统计量 | 数值 |
|---|---|
| Pearson r | **+0.515**（p = 0.034） |
| Spearman ρ | **+0.510**（p = 0.037） |
| 时长加权 Pearson r | +0.363 |
| OLS 斜率 | +0.786（截距 +0.611） |

**正向显著相关**：潮汐引力红移在钟比值里以**正确方向、部分幅度**被检出。
OLS 斜率 ≈ +0.79，与既往基于拍频幅度比的结论（幅度比 |A| ≈ 0.5，方向一致）
相互印证「实验检出潮汐趋势，幅度约理论的一半」。

### 4.2 整体均值（时长加权）

权重 `w_i = n_i / Σn_i`（有效点数，即测试时长）：

```text
y_i 时长加权整体均值   = −0.408 × 10⁻¹⁸
y_i 算术均值           = +0.146 × 10⁻¹⁸
Δf/f 时长加权整体均值  = −0.365 × 10⁻¹⁸
Δf/f 算术均值          = −0.592 × 10⁻¹⁸
```

时长加权后 y_i 均值由正的 +0.146 反转为负的 **−0.408 × 10⁻¹⁸**，说明长时段
（第 13、16 段，合计 ~24 h，占比 ~30%）的负 y_i 主导了整体均值——这与
「潮汐综合差全段方向为负（武汉−上海）」的物理预期一致。

### 4.3 整体修正量

**整体潮汐修正量 = 时长加权 Δf/f = −0.365 × 10⁻¹⁸**。物理含义是将潮汐引力
红移项从钟比值中扣除，得到「无潮汐」的 Yb/Sr 比值：

```text
R_corrected ≈ R_raw × (1 − Δf/f) = R_raw × (1 + 0.365×10⁻¹⁸)
```

整体修正量（−0.365×10⁻¹⁸）与 y_i 时长加权均值（−0.408×10⁻¹⁸）同量级同符号，
表明钟比值偏差的主要部分确来自潮汐引力红移，幅度比约 **|A| = 0.41/0.37 ≈ 1.1**，
或从相关性斜率看 **A ≈ +0.79**。

## 5. 结论

| 维度 | 结果 |
|---|---|
| 钟比值中心值 | R_ref = 1.2075070393433377209…，与实验方 WLS 差 −0.38×10⁻¹⁸ |
| 逐段偏差量级 | y_i ∈ [−4.6, +6.6]×10⁻¹⁸，单段不显著 |
| 整体相关性 | Pearson r = +0.515（p=0.034），正相关显著 |
| 整体均值（时长加权） | y_i = −0.408×10⁻¹⁸ |
| 整体修正量 | Δf/f = −0.365×10⁻¹⁸，与 y_i 均值同量级同符号 |

**核心结论**：武汉—上海 Yb/Sr 光钟比对中，（1）逐段钟比值已按 MATLAB 80 位
精度公式重建，与实验方中心值吻合至 0.38×10⁻¹⁸；（2）潮汐引力红移在 17 段
钟比值偏差中**以正确方向、约一半幅度被检出**（r = +0.515，p = 0.034）；（3）
时长加权的整体修正量与整体偏差同量级同符号，确认偏差主要来源于潮汐项，且
幅度比约 0.8。
