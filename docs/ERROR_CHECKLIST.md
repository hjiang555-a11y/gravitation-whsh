# 错误清单与检查项目（ERROR CHECKLIST）

> 本文件沉淀本项目中**真实发生过的错误**，并从中提取出**可执行的检查项目**。
> 每项工作收尾前，对照本清单逐条自查。凡涉及「物理系数 / 归一化 / 量纲 /
> 符号约定 / 概念正确性」的任务，还需触发 L4 对抗性检查（独立 sub-agent）。
>
> 配套文件：[docs/NOTATION.md](NOTATION.md)（符号表）、[clock/shared.py](../clock/shared.py)
> （代码单一真源）。

## 一、错误清单（真实发生的 6 类）

| # | 错误 | 现象 | 根因 |
|---|---|---|---|
| 1 | 数值精度被语言默认类型吞掉 | float64 算钟比值，17 段 y_i 几乎全 0、只有段 9=−222 | R≈1.2 时 float64 绝对精度 ~260e-18，与真实段间差异 (~1-5e-18) 差两个数量级 |
| 2 | 两个同形不同义的系数混淆 | 潮汐拍频归一化误用 `COEF`，幅度比 A 差 1.2075 倍 | `COEF`（比值偏移，隐含 1/COEF=233.53 THz）与 `1/F_1550`（光频归一化，F_1550=193.40 THz）量纲相同、数值相近，但物理基准不同 |
| 3 | 拿参考文档当真理去硬对齐 | 端点筛选 remove 数反复核对 PDF 表 7+ 轮 | 把 PDF 结果表当标准答案，而非用原始数据+规则独立算再反校验 |
| 4 | 自作主张删/改已确立的东西 | 未经确认删除端点筛选、删除 delta_g 静态引力修正 | 把用户某句话过度外推，擅自改动不该动的东西 |
| 5 | 声明通过 ≠ 真正验证 | 仅 `print('语法 OK')` 就当验证，或声稱一致但未 diff | 把「应该能跑」当「跑过了」 |
| 6 | 报告数值口径前后不一致 | 钟比值一会儿写 7210、一会儿 721/72095 | 同一个数全文未统一位数与四舍五入口径 |

## 二、检查项目（逐条可执行）

### 错误 1 → 精度检查

- [ ] 凡量级差 ≥2 个数量级的小量计算，先确认数值类型够不够位（E-18 精度 → 必须 `decimal`/高精度，禁 float64）。
- [ ] 打印或对比极小差异时，禁止用 float 相减；用 `Decimal` 精确相减。
- [ ] 结果「全 0」或「全相同」是精度不足的**红旗**，立即怀疑数值类型，而非怀疑数据本身。

### 错误 2 → 系数归一化检查

- [ ] 出现「拍频 → 某无量纲量」的系数时，追问：归一化基准是**光频**还是**钟比值**？
- [ ] 系数值差 ~1.2 倍且与 Yb/Sr ≈ 1.2075 挂钩 → 高度怀疑混用了比值基准。
- [ ] 两个同量纲系数必须显式命名区分：`COEF`（拍频→Sr/Yb 比值偏移）vs `1/F_1550`（拍频→光频相对频移）。

### 错误 3 → 参考对齐检查

- [ ] 对不齐参考文档数字 >2 轮 → 停止，质疑「参考是否自洽」，而非继续硬对齐。
- [ ] 校验顺序固定为：**原始数据独立算 → 再与参考对比**，禁止反着来。

### 错误 4 → 授权检查

- [ ] 删除/修改任何已确立的物理项（delta_g、端点筛选、方向约定）前，确认是「用户显式指令」还是「我的臆断」。
- [ ] 用户说「修正 X」时，先确认 X 的精确定义（例：「引力潮汐修正」≠「静态引力修正 delta_g」）。

### 错误 5 → 真实验证检查

- [ ] 代码改动 → 必须 `python xxx.py` 真实运行并查看 stdout，非仅语法检查。
- [ ] 声称「结果一致」→ 必须 diff 输出，不能凭印象。

### 错误 6 → 数值口径检查

- [ ] 报告里同一个数，全文必须同一位数、同一四舍五入口径。
- [ ] 关键数值写入文档后，程序化核对（CSV vs 文档表格）。

## 三、检验层级（L0–L5）

| 层级 | 动作 | 适用 |
|---|---|---|
| L0 | `git status` 确认干净/一致 | 每次任务收尾 |
| L1 | 真正 `python` 运行（非只语法检查） | 任何代码改动 |
| L2 | 结果与预期/上轮 diff | 数值计算 |
| L3 | CSV/文档/图逐项核对 | 报告文档 |
| L4 | 独立 sub-agent（oracle/momus）对抗审查 | 见触发条件 |
| L5 | 换路径独立复现 | 关键结论 |

## 四、L4 对抗性检查触发条件

以下任一情形，**必须**在动手/定论之前 fire 独立 sub-agent 做对抗审查：

1. 涉及**物理系数 / 归一化基准 / 量纲**的改动；
2. **概念正确性**判断（如「这个量是比值偏移还是频率相对变化」）；
3. **符号约定 / 方向约定**的判断；
4. 全局缩放下「哪些量变 / 哪些不变」的判断；
5. 修正一个「用户点出我错了」的问题时——先对抗检查我理解对不对，再改。

对抗检查交给 sub-agent 的核心问题：
- 这个系数的物理量纲/归一化基准是什么？有没有同形不同义的量被混用？
- 全局等比例缩放下，哪些统计量不变、哪些变？我的判断对吗？
- 符号/方向约定有没有歧义？
- 我是否在拿「参考文档结论」当真理，而不是用「原始数据验算」？

## 五、新增潮汐修正专项检查（不改历史基线）

本节是新增分析的防错要求，不将每项风险都宣称为已经发生过的错误。
方法见 [METHODOLOGY §9](METHODOLOGY.md#9-新增固定响应系数的潮汐修正与段内稳定度)，
结果见独立 [REPORT.md](../clock_ratio/tidal_correction/REPORT.md)。

### 5.1 符号、样本与时间

- [ ] `ΔW=W(武汉)−W(上海)`，`h=F_1550·ΔW/c²`；h 不预加负号、不去均值，不使用 `1/COEF` 生成模板。
- [ ] A 是 `b_raw=noise+A·h` 的**响应系数**；修正是 `b_corr=b_raw−A·h`。固定 A=−1 加 h，A=−0.54 加 0.54h；本次不重拟合。
- [ ] 三情景使用完全相同的原始段窗口、含两端扣除区间、全局中位数、跳点筛选、最长有效索引段和两端裁剪；修正后不重新筛选。
- [ ] 不把旧 `longest_valid_span` 误写成保证时间连续：它只检查索引掩码。时间间断两侧保留样本仍参与比值；OADEV 遇每个非 1 s 步长（含重复时间戳）断开。
- [ ] 使用**实际裁剪后**保留样本时间戳，北京时间减 8 h 后查询潮汐；不能用旧 CSV 中裁剪前边界代替。
- [ ] 潮汐时间/数值有限，UTC 30 s 刻度有序且无重复；查询不超覆盖范围，所需插值两端相隔 30 s。不外推、不钳位、不跨缺失区间插值。
- [ ] 三情景逐组 `n_valid` 一致；`duration_s=n_valid×1 s`，不能用可能含间断的 `elapsed_span_s` 代替权重。

### 5.2 精度、反演与变化量

- [ ] 沿用旧原始 float64 均值，经 `repr` 转 Decimal；明确 Decimal 不恢复已损失的原始均值量化精度。
- [ ] 在 Decimal80 中计算 `mean_dm_corr=to_dec(raw_mean)−m_dec−A·to_dec(mean(h))`，随后调用完整 `full_ratio`；不向 MHz 浮点拍频或数量级为 1 的浮点比值直接叠加微小量。
- [ ] 先平均修正后的线性拍频、再反演，不平均瞬时比值；`DELTA_G`、`shift_a` 及完整 Dr 常数保持不变。
- [ ] [summary.json](../clock_ratio/tidal_correction/summary.json) 的 `R_duration` 与 [ratio_scenarios.csv](../clock_ratio/tidal_correction/ratio_scenarios.csv) 按同一 `n_valid` 权重汇总一致；不换成 WLS。
- [ ] R 从完整 Decimal 按 `ROUND_HALF_EVEN` 舍入到小数点后 22 位；不先转 float 或截断字符串，显示位数不作为准确度声明。
- [ ] `delta_R=R−R_raw` 是带符号绝对比值差，`delta_fractional_1e18=(R/R_raw−1)×10¹⁸` 是分数变化；先用未舍入值计算，再展示。两者不混用，也不是 `mean_dff_1e18`。

### 5.3 稳定度与解释边界

- [ ] 同组所有情景共用 raw 参考 R0；`S0=(1+DELTA_G)/R0`，K 来自该段完整 Dr 常数而非舍入 `COEF`，`q=(K/S0)·[(b−raw_mean)−A·h]`，直接计算 `y=−q/(1+q)`。
- [ ] 新 OADEV 在每个连续 run 内使用全部起点 `j=0,…,N_run−2m`；平方差与对数仅在同组内汇总，分母为 `2·n_pairs`，其中 `n_pairs=Σ_runs max(N_run−2m+1,0)`，不是独立自由度。
- [ ] τ 为二进制秒数加 600、1200、3600、7200 s，均不超过最长 raw run 长度的 1/4；三情景网格一致，不去趋势。样本标准差使用 `ddof=1`。
- [ ] 长 τ 不可用或 raw OADEV 为零时，不把缺失 OADEV/倍数填零；报告计数的分母只包括该 τ 可比较的组。
- [ ] 所有 corrected/raw 倍数来自同一个新 OADEV 算法；旧 `statistical_methods.oadev` 实际是不重叠块均值算法，保留旧输出，不把新旧算法之差归因为潮汐。
- [ ] −0.54 从去均值波形转用到未去均值 DC 均值是额外假设，不称为校准；固定负号不称为新验证的硬件极性。
- [ ] 方向自检用「修正后相关性消失」而非符号链：沿历史 1200-s 三角窗去均值处理链构造 `resid=beat−A_fix·tide`，A_fix=−0.54 时残差段均值 r≈0、带符号 Stouffer |z| 不显著、负相关段随机；残差相关性零点应落在 A_fix≈−0.54。不依赖未定死的 s_beat。
- [ ] 方向自检只覆盖去均值波形（无 DC），不据此宣称潮汐 DC 已被校准；且残差 |z|（符号无关）与 Fisher p 仍略显著时如实记录，不夸大为「相关完全消失」。
- [ ] 不声称所有段改善；较低 OADEV 只是指定 τ 下的描述性结果，不等于统计显著或准确度提高。
- [ ] OADEV/样本标准差不是 SEM；没有传播系数、潮汐模型或系统项不确定度，不据此生成新 WLS 或总不确定度。
