> 每项工作收尾前，对照本清单逐条自查。凡涉及「物理系数 / 归一化 / 量纲 /
> 符号约定 / 概念正确性」的任务，还需触发 L4 对抗性检查（独立 sub-agent）。
>
> 配套文件：[docs/NOTATION.md](NOTATION.md)（符号表）、[clock/shared.py](../clock/shared.py)

## 一、错误清单（真实发生的 6 类）

| # | 错误 | 现象 | 根因 |
|---|---|---|---|
| 1 | 数值精度被语言默认类型吞掉 | float64 算钟比值，17 段 y_i 几乎全 0、只有段 9=−222 | R≈1.2 时 float64 绝对精度 ~260e-18，与真实段间差异 (~1-5e-18) 差两个数量级 |
| 2 | 两个同形不同义的系数混淆 | 潮汐拍频归一化误用 `COEF`，幅度比 A 差 1.2075 倍 | `COEF`（比值偏移，隐含 1/COEF=233.53 THz）与 `1/F_1550`（光频归一化，F_1550=193.40 THz）量纲相同、数值相近，但物理基准不同 |
| 3 | 拿参考文档当真理去硬对齐 | 端点筛选 remove 数反复核对 PDF 表 7+ 轮 | 把 PDF 结果表当标准答案，而非用原始数据+规则独立算再反校验 |
| 4 | 自作主张删/改已确立的东西 | 未经确认删除端点筛选、删除 delta_g 静态引力修正 | 把用户某句话过度外推，擅自改动不该动的东西 |
| 5 | 声明通过 ≠ 真正验证 | 仅 `print('语法 OK')` 就当验证，或声稱一致但未 diff | 把「应该能跑」当「跑过了」 |
| 6 | 报告数值口径前后不一致 | 钟比值一会儿写 7210、一会儿 721/72095 | 同一个数全文未统一位数与四舍五入口径 |

## 二、检查项目（逐条可执行）

### 错误 1 → 精度检查

- [ ] 凡量级差 ≥2 个数量级的小量计算，先确认数值类型够不够位（E-18 精度 → 必须 `decimal`/高精度，禁 float64）。
- [ ] 打印或对比极小差异时，禁止用 float 相减；用 `Decimal` 精确相减。
- [ ] 结果「全 0」或「全相同」是精度不足的**红旗**，立即怀疑数值类型，而非怀疑数据本身。

### 错误 2 → 系数归一化检查

- [ ] 出现「拍频 → 某无量纲量」的系数时，追问：归一化基准是**光频**还是**钟比值**？
- [ ] 系数值差 ~1.2 倍且与 Yb/Sr ≈ 1.2075 挂钩 → 高度怀疑混用了比值基准。
- [ ] 两个同量纲系数必须显式命名区分：`COEF`（拍频→Sr/Yb 比值偏移）vs `1/F_1550`（拍频→光频相对频移）。

### 错误 3 → 参考对齐检查

- [ ] 对不齐参考文档数字 >2 轮 → 停止，质疑「参考是否自洽」，而非继续硬对齐。
- [ ] 校验顺序固定为：**原始数据独立算 → 再与参考对比**，禁止反着来。

### 错误 4 → 授权检查

- [ ] 删除/修改任何已确立的物理项（delta_g、端点筛选、方向约定）前，确认是「用户显式指令」还是「我的臆断」。
- [ ] 用户说「修正 X」时，先确认 X 的精确定义（例：「引力潮汐修正」≠「静态引力修正 delta_g」）。

### 错误 5 → 真实验证检查

- [ ] 代码改动 → 必须 `python xxx.py` 真实运行并查看 stdout，非仅语法检查。
- [ ] 声称「结果一致」→ 必须 diff 输出，不能凭印象。

### 错误 6 → 数值口径检查

- [ ] 报告里同一个数，全文必须同一位数、同一四舍五入口径。
- [ ] 关键数值写入文档后，程序化核对（CSV vs 文档表格）。

## 三、检验层级（L0–L5）

| 层级 | 动作 | 适用 |
|---|---|---|
| L0 | `git status` 确认干净/一致 | 每次任务收尾 |
| L1 | 真正 `python` 运行（非只语法检查） | 任何代码改动 |
| L2 | 结果与预期/上轮 diff | 数值计算 |
| L3 | CSV/文档/图逐项核对 | 报告文档 |
| L4 | 独立 sub-agent（oracle/momus）对抗审查 | 见触发条件 |
| L5 | 换路径独立复现 | 关键结论 |

---

## 四、L4 对抗性检查触发条件

以下任一情形，**必须**在动手/定论之前 fire 独立 sub-agent 做对抗审查：

1. 涉及**物理系数 / 归一化基准 / 量纲**的改动；
2. **概念正确性**判断（如「这个量是比值偏移还是频率相对变化」）；
3. **符号约定 / 方向约定**的判断；
4. 全局缩放下「哪些量变 / 哪些不变」的判断；
5. 修正一个「用户点出我错了」的问题时——先对抗检查我理解对不对，再改。

对抗检查交给 sub-agent 的核心问题：
- 这个系数的物理量纲/归一化基准是什么？有没有同形不同义的量被混用？
- 全局等比例缩放下，哪些统计量不变、哪些变？我的判断对吗？
- 符号/方向约定有没有歧义？
- 我是否在拿「参考文档结论」当真理，而不是用「原始数据验算」？
