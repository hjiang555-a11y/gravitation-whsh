## 2. 钟比值（Yb/Sr）

**权威钟比值结果**：Yb/Sr = **1.207 507 039 343 337 721**
（R_ref = `1.20750703934333772095107679839…`）。

## 3. 拍频 → 比值偏移（Dr 公式）

| 符号 | 含义 | 值 |
|---|---|---|
| `beat`（`b`） | 1550 nm 环外拍频（FXE_B8） | ~33 623 140 Hz |
| `m` | 拍频全局中位数（去跳点后） | ~33 623 140.92 Hz |
| `mean_dm` | 段内拍频相对 m 的平均偏差 = `mean(d_long − m)` | Hz |
| `Dr` | 拍频偏差 → Sr/Yb 比值偏移 | 无量纲 |
| `COEF` | 拍频[Hz] → **Sr/Yb 比值偏移**的换算系数（Dr 公式） | 4.282082163269648e-15 |
| `F_1550` | 1550 nm 传递光频率 = `N1550_WH × f_rep`（拍频归一化基准） | 193 399 200 000 000 Hz ≈ 193.40 THz |
| `f_rep` | 光梳重复率 = `fref × div20` | 200 MHz |
| `fref` | 梳齿重复频率基准 | 1e7 = 10 MHz |
| `div20` | 分频 | 20（fref×div20 = 200 MHz = f_rep）|

> **⚠️ COEF 与 F_1550 的区别（易错点）**：`COEF` 是钟比值 Dr 公式的系数，
> 隐含光学频率 `1/COEF ≈ 233.53 THz`；而拍频物理上归一化到 **1550 nm 传递光**
> `F_1550 ≈ 193.40 THz`。两者差 `(1/COEF)/F_1550 ≈ 1.2075 = Yb/Sr` 倍。
> **潮汐拍频模板必须用 `F_1550` 归一化**（`tide_beat = (ΔW/c²) × F_1550`），
> 不能用 `1/COEF`，否则幅度比 A 被系统性低估 1/1.2075 ≈ 0.828 倍。

### 5.1 shift_a 五个分量

| 符号 | 含义 | 第一轮/第二轮典型值 |
|---|---|---|
| `a_rou` | 光晶格 AC-Stark 频移 | ~−2.3×10⁻¹⁹ / ~−3.5×10⁻¹⁹ |
| `a_AC` | 交流斯塔克频移 | +7.444×10⁻¹⁸ / +8.929×10⁻¹⁸ |
| `a_SM` | 二阶塞曼频移 | ~−1.78×10⁻¹⁶ / −8.925×10⁻¹⁷（段9）、0（段10–14）|
| `a_air` | 空气折射率修正 | −6.7×10⁻¹⁹ |
| `a_BBR` | 黑体辐射频移 | 0 |

`shift_a_i = a_rou_i + a_AC_i + a_SM_i + a_air_i + a_BBR_i`（14 段；第 15/16/17
段沿用段 12–14 的常数 shift_a）。

> **遗留疑点**：段 9 的 `a_SM = −8.925×10⁻¹⁷` 与段 10–14 的 `a_SM = 0` 差
> 8.925×10⁻¹⁷，MATLAB 源码自注「8 月 a_SM=0 请确认是实际修正值还是占位符」。
> 本项目按「尊重原始数据」原则原样保留。

## 7. 相关性分析量

## 8. 时区约定

- 拍频时间戳：**北京时间（UTC+8）**。
- 潮汐 CSV：**UTC**。
- 比对前，拍频窗口 **−8 h** 对齐到 UTC 后再取潮汐。

## 9. 方向约定

- 专业潮汐「综合差」方向 = **武汉 − 上海**（CAS − SHA），即 `ΔW = W(WUHN) − W(SHAO)`。
- 潮汐引力红移：`Δf/f = ΔW / c²`。
